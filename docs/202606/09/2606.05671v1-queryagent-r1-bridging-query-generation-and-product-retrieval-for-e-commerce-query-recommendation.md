## 摘要
电商搜索中的查询推荐旨在主动推荐与用户潜在兴趣匹配的查询词。然而，现有方法主要优化查询层面的相关性，忽略了检索到的商品是否契合用户的下游偏好。这种不匹配常导致查询点击率高但商品转化率低。为弥合这一差距，我们提出QueryAgent-R1，一种通过检索链优化来改进端到端对齐的记忆增强智能体框架。我们的QueryAgent-R1将查询生成锚定于真实库存检索，使智能体能够基于检索到的商品验证并优化查询。我们还在智能体强化学习过程中设计了一致性奖励，以联合优化查询相关性与下游参与度。此外，我们构建了记忆抽象模块以实现高效的用户画像。为支持离线评估，我们基于专有工业数据和公开数据集构建了两个数据集，QueryAgent-R1在这些数据集上持续优于强基线。在大型生产平台上，在线A/B测试中QueryAgent-R1使查询点击率提升2.9%，引导转化率提升3.1%。

## Abstract
Query recommendation in e-commerce search aims to proactively suggest queries that match users' potential interests. However, existing methods mainly optimize query-level relevance, while neglecting whether the retrieved products align with users' downstream preferences. This mismatch often leads to high query click through rates (CTR) but low product conversion rates (CVR). To bridge this gap, we propose QueryAgent-R1, a memory-augmented agentic framework that improves end-to-end alignment via chain-of-retrieval optimization. Our QueryAgent-R1 grounds query generation in real inventory retrieval, allowing the agent to validate and refine queries based on retrieved products. We also design a consistency reward in the agentic reinforcement learning (RL) process to jointly optimize query relevance and downstream engagement. In addition, we construct a memory abstraction module for efficient user profiling. To support offline evaluation, we construct two datasets based on both proprietary industrial data and public datasets, on which QueryAgent-R1 consistently outperforms strong baselines. Moreover, on a large scale production platform, QueryAgent-R1 improves Query CTR by 2.9% and guided CVR by 3.1% in online A/B tests.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：电商搜索中，查询推荐（query recommendation）旨在主动推荐与用户兴趣匹配的查询。但现有方法仅优化**查询层面相关性**（如点击率），忽略了检索到的商品是否真正契合用户的下游偏好（如购买意图），导致**“高查询CTR、低商品CVR”**的生成-检索脱节问题。
- **背景**：尤其在搜索框占位符场景（search-bar placeholder），仅展示一个预填充查询，推荐质量直接影响用户参与和转化。现有工业方法依赖库存匹配（如ItemCF、Swing）或独立语义检索（如DSSM、LLM），均未实现端到端的产品级对齐。

## 2. 方法论

### 核心思想
提出**QueryAgent-R1**，一个**记忆增强的智能体框架**，通过**链式检索优化（Chain-of-Retrieval）**将查询生成锚定于真实库存检索，并采用**一致性奖励（Consistency Reward）**进行强化学习联合优化，桥接生成与检索的差距。

### 关键技术细节
1. **记忆抽象机制**  
   - 利用Qwen3-Next-80B-A3B离线将用户超长行为日志（>10^4 tokens）压缩为结构化用户画像（最新意图、兴趣图谱、潜在身份等），实现10×压缩。
   - 智能体通过`Fetch_Memory`工具直接检索缓存画像，实现高效用户建模。

2. **产品检索增强**  
   - 构建包含400万真实商品的检索沙箱，采用BM25（稀疏检索）+ Qwen3-Embedding-0.6B（稠密检索）混合检索，再经Qwen3-Rerank-0.6B交叉编码重排序。
   - 智能体在生成查询时调用`Product_Search`工具，验证返回产品是否相关、可购买，并据此优化查询。

3. **智能体强化学习（Agentic RL）**  
   - 训练策略：基于Qwen3-4B作为策略模型，使用**GDPO**（Group Reward-Decoupled Normalization Policy Optimization）优化，相比GRPO更适应多奖励信号场景。
   - 奖励函数：  
     ```
     R(y) = λ_fmt r_fmt + λ_tool r_tool + λ_hit r_hit
     ```
     其中 `r_hit` 包含查询奖励（Exact Match + ROUGE）和商品奖励（Hit Rate + 标题ROUGE），实现稀疏-稠密信号结合。
   - 优化目标：最大化`P(Query CTR) · P(Item CTR)`，即同时对查询点击和后续商品点击进行建模。

## 6. 主要结论与发现

- QueryAgent-R1在离线两个数据集上均实现最优的Cons@1（工业0.117，Amazon 0.063），大幅超越强基线（如Gemini-3.1-pro Cons@1仅0.021/0.019）。

- 消融表明：记忆抽象贡献最大（Cons@1从0.031→0.064），RAG重排序进一步提升（0.064→0.117）。单独加检索或RL贡献有限，说明**联合优化**是关键。
- GDPO相比GRPO在多奖励场景下收敛更快、稳定性更高。

## 7. 优点

- **端到端对齐**：创新性地将查询生成与真实库存检索联合优化，直接解决工业痛点。
- **记忆与检索协同**：记忆抽象实现高效用户画像（10×压缩），检索沙箱提供实时产品验证，两者通过RL训练深度融合。
- **奖励设计合理**：结合稀疏（Exact Match、Hit Rate）与稠密（ROUGE、标题ROUGE）信号，缓解奖励稀疏问题。
- **实验充分**：覆盖工业与公开数据、多种LLM基线、多维度消融、在线A/B验证，结论可靠。
- **可部署性**：通过异步预处理掩盖延迟，实现在生产环境大规模服务。

- **伦理考量**：虽提及数据脱敏和内容安全，但未深入讨论对用户浏览行为的隐私推断风险。
