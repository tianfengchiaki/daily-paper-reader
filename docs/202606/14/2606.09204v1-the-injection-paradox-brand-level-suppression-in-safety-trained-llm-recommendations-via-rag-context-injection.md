## 摘要
我们提出了一种基于RAG的大模型推荐中安全训练的可复现失效模式——注入悖论，其中嵌入在检索文档中的提示注入会适得其反对抗攻击者，将目标品牌抑制到低于无注入基线的水平。在经过安全训练的Claude模型中，包含提示注入的文档推荐率急剧下降，且这种抑制会从注入文档传播到同一品牌的其他未修改文档。在Claude Opus 4.6中，目标品牌在全部50次试验中从54%的基线降至零个前二推荐，尽管语料库中4个品牌文档中只有1个包含注入。该方向性模式在反事实实验和三个品牌中均得到复现。在测试的GPT模型中出现了相反结果，相同的注入反而增加了推荐，表明不同模型家族中注入类上下文对推荐行为的影响存在差异。这些发现提出了一个反向攻击场景的技术可能性，即攻击者将注入嵌入竞争对手的文档中，通过安全敏感的模型行为来抑制竞争对手的品牌。

## Abstract
We present a reproducible failure mode of safety training in RAG-based LLM recommendation -- the Injection Paradox -- in which prompt injections embedded in retrieved documents backfire against the attacker, suppressing the target brand below the injection-free baseline. In safety-trained Claude models, documents containing prompt injections suffer a sharp drop in recommendation rate, and this suppression propagates beyond the injected document to unmodified documents of the same brand. In Claude Opus 4.6, the target brand drops from a 54% baseline to zero top-2 recommendations across all 50 trials, even though only 1 of 4 brand documents in the corpus contains an injection. The directional pattern is reproduced in counterfactual experiments and across three brands. A contrasting result across the GPT models tested, where the same injection instead increases recommendations, suggests model-family differences in how injection-like context affects recommendation behavior. These findings raise the technical possibility of a reverse-attack scenario in which an adversary embeds injections in a competitor's documents to suppress the competitor's brand via safety-sensitive model behavior.

- **核心问题**：大型语言模型（LLM）在RAG（检索增强生成）推荐系统中，当检索文档被嵌入提示注入（prompt injection）时，安全训练（safety training）可能产生非预期的副作用——不仅无法阻止攻击，反而会过度抑制被注入品牌甚至其同品牌其他未修改文档的推荐，形成“注入悖论”。
- **研究动机**：已有研究关注间接提示注入的风险，但未充分探讨安全训练与注入的交互效应。微软2026年报告显示31家公司曾被隐藏提示操纵AI推荐。本文旨在揭示安全训练本身可能引发的新攻击面。
- **整体含义**：提出一种可复现的失效模式：在通过Constitutional AI（CAI）训练的安全Claude模型中，注入效果会“适得其反”（降低目标推荐率），而在RLHF训练的GPT模型中则相反（提升推荐率）。这种差异暗示模型家族间的对齐机制不同，并可能被对手利用进行“反向攻击”——在竞争对手的文档中嵌入注入来压制其品牌。

## 6. 论文的主要结论与发现

- **注入悖论确认**：
  - 在Claude Sonnet 4.6和Opus 4.6中，注入条件导致目标品牌推荐率显著低于基线（Sonnet: 26%→8%，-18pp；Opus: 54%→8%，-46pp）。组合条件下Opus降至0%（-54pp）。
  - 在GPT-4o-mini中，相同注入反而促进推荐（17%→40%，+23pp）。GPT-5系列方向一致（全部促进）。
- **品牌级抑制传播**：
  - 仅1/4的Edifier文档被注入，但其余3个未修改文档也完全被排除（top-2推荐为零）。反事实实验显示：存在注入（0%）比移除注入文档（28%）结果更差（“比缺失更糟效应”）。
- **跨品牌复现**：Edifier（-54pp）、Apple（-34pp）、Galaxy（-14pp）均呈现从Haiku（促进）到Sonnet/Opus（抑制）的下降趋势，表明模型级模式而非品牌特定伪影。
- **语料库范围不信任假设被排除**：当注入移至Apple文档时，Edifier推荐率无显著变化，说明抑制并非全局性的语料库不信任。
- **防御效果有限**：四种提示级防御（D1-D4）均未能恢复干净基线，最高恢复仅达36%（D4 in Opus），且在Sonnet上恢复更小（22%）。客观规格锚定（非注入警告）是主要恢复驱动因素，但存在模型间不一致。
- **反向攻击技术可能性**：攻击者只需在对手的单个文档中嵌入注入，即可使整个品牌在安全训练模型中消失，无需梯度或对抗文本优化。
