## 摘要
定向广告系统可将广告主选择的受众与暴露可见用户行为的广告单元配对。当交互行为仍与引发它的广告活动保持关联时，广告主可能收到绑定到特定用户的观测结果，而不仅仅是汇总报告。我们将该信道建模为用于属性推断的带噪声预言机。该模型区分了定向谓词、曝光、交互和披露。这些边界捕捉了资格与投放之间的差距，以及交互与广告主可见性之间的差距。我们使用通过公共数据校准的合成总体构建了一个可复现的基准，每个总体具有已知的敏感标签。生成的广告活动语义层提供了主题变体和响应先验。模拟器生成真实标签、事件轨迹、披露的观测结果和评估指标。评估在共同的广告活动和披露定义下比较了贝叶斯、监督、正例无标签和自适应攻击。最终评估使用了四个主题变体、七个模拟器种子和两种交互设置。具有身份暴露的重复广告活动产生可测量但有界的推断信号。在160个广告活动时，主设置中贝叶斯和监督攻击的AUC约为0.64，较高交互设置中约为0.65。披露策略是最强的控制手段。汇总报告移除了与用户绑定的评估预言机输入。类型过滤和随机披露减少了释放的信号。研究成果是一个适用于交互式定向广告隐私保护的模型、工件和防御评估方法。代码可在 https://github.com/P-HOW/Interactive-Ad-Oracle 获取。

## Abstract
Targeted advertising systems can pair audiences selected by advertisers with ad units that expose visible user actions. When an interaction remains linked to the campaign that elicited it, the advertiser may receive an observation tied to a user rather than only an aggregate report. We model that channel as a noisy oracle for attribute inference. The model separates targeting predicates, exposure, interaction, and disclosure. These boundaries capture the gap between eligibility and delivery, and the gap between interaction and advertiser visibility.   We build a reproducible benchmark using synthetic populations calibrated with public data, each with known sensitive labels. A generated campaign semantics layer provides topic variants and response priors. The simulator generates the ground truth, event traces, disclosed observations, and metrics. The evaluation compares Bayesian, supervised, positive and unlabeled, and adaptive attacks under common campaign and disclosure definitions.   The final evaluation uses four topic variants, seven simulator seeds, and two interaction settings. Repeated campaigns with identity exposure produce measurable but bounded inference signal. At $160$ campaigns, Bayesian and supervised attacks reach about $0.64$ AUC in the main setting and about $0.65$ AUC in the higher interaction setting. Disclosure policy is the strongest control. Aggregate reporting removes the evaluated oracle input tied to users. Type filtering and randomized disclosure reduce the released signal. The result is a model, artifact, and defense evaluation method for privacy in interactive targeted advertising. The code is available at https://github.com/P-HOW/Interactive-Ad-Oracle.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在交互式定向广告系统中，广告主可以创建广告活动并选择定向谓词，当用户与广告发生交互（如评论、点赞）且该交互暴露了用户身份时，广告主就能获得一个绑定到特定用户的观测。这种观测能否被广告主用作“噪声预言机”，从而推断用户的敏感属性（如健康兴趣、政治倾向、财务压力等）？
- **研究动机**：已有工作表明定向广告的受众构建和估计可能泄露信息，但缺少对“交互暴露身份”这一特定信道进行系统建模、攻击与防御评估的通用框架。作者希望填补这一空白，为平台提供隐私风险评估工具。
- **整体含义**：论文将交互式定向广告的隐私风险形式化为一个噪声属性推断问题，并提供了可复现的基准测试和防御评估方法，以帮助平台理解并控制用户信息通过交互接口外泄的风险。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将定向广告系统抽象为一个噪声预言机，其输出由四个分离的阶段决定：定向谓词（广告主选择的条件）、曝光（用户是否看到广告）、交互（用户是否与广告互动）、披露（平台通过何种策略将交互记录暴露给广告主）。攻击者可以通过多次广告活动收集用户交互历史，利用贝叶斯后验或学习模型推断用户属性。
- **关键技术细节**：
    - **系统与预言机模型**：
        - 用户集合 \(U\)，每个用户有特征 \(X_u\) 和二进制敏感属性 \(S_u\)。
        - 广告活动 \(c = (g_c, a_c, b_c)\)，其中 \(g_c\) 是定向谓词，\(a_c\) 是话题，\(b_c\) 是预算。
        - 曝光事件 \(E_{u,c} \sim \text{Bernoulli}(p_E(u,c))\)，交互事件 \(R_{u,c}\) 仅在曝光后可能发生，\(P(R_{u,c}=1 | E_{u,c}=1) = p_R\)。
        - 披露策略 \(D\) 决定哪些交互记录变为可见观测 \(Y_{u,c}\)（如身份暴露、类型过滤、随机披露、阈值披露、聚合报告）。
        - 用户历史 \(H_u^{(T)} = ((c_t, g_{c_t}, a_{c_t}, b_{c_t}, Y_{u,c_t}))_{t=1}^T\)，攻击目标是用 \(f(H_u^{(T)})\) 估计 \(S_u\)。
    - **攻击方法**：
        - **贝叶斯攻击**：假设条件独立，计算后验对数几率。
        - **监督攻击**：使用逻辑回归、随机森林、梯度提升树学习映射 \(\phi(H_u^{(T)}) \to S_u\)。
        - **正例无标签攻击**：区分闭世界（缺失视为负例）和开世界（缺失视为未标注）设置。
        - **自适应攻击**：基于期望信息增益选择下一个广告活动，最大化每单位成本的信息减少。
- **算法流程**：攻击者 → 选择合法广告活动 → 平台执行曝光/交互 → 按披露策略释放结果 → 对目标用户收集历史 → 使用 \(f\) 推断属性。自适应攻击者还会根据历史选择后续活动。

## 6. 主要结论与发现

- **RQ1**：重复广告活动配合身份暴露，可以在用户历史中产生可测量但受限的推断信号。在主要设置下，160 个广告活动后贝叶斯和监督攻击的 AUC 约 **0.64**，高交互设置下约 **0.65**。
- **RQ2**：推断信号随广告活动数量和交互密度增加而增长；谓词粒度并非越细越好（长谓词因最小受众约束导致交互机会减少，AUC 接近先验）。
- **RQ3**：高置信度阈值穿越（\(\max(s,1-s) \ge 0.70\)）在主设置下仅约 17.2%，高交互设置下约 29.8%，说明多数用户难以达到高置信度，但有提升空间。
- **RQ4**：**披露策略是最强的控制手段**。聚合报告完全消除用户级历史（AUC=0.5）；类型过滤和随机身份披露降低 AUC 约 0.04–0.05；阈值披露在本实验中效果有限（因事件率低，阈值未生效）。
- **话题变体稳健性**：结果在不同种子和话题上稳定，说明信道主要受模拟器参数而非语义影响。

## 7. 优点

- **形式化清晰**：将交互式广告泄露建模为噪声预言机，分离了定向、曝光、交互、披露四个阶段，为后续研究提供了理论框架。
- **可复现基准**：提供了完整代码和模拟器，支持参数扫描、攻击对比和防御评估，降低了研究门槛。
- **多维度攻击比较**：包括了贝叶斯、监督、正无标签和自适应攻击，对比了预测策略和广告选择策略两个维度，分析全面。
- **防御评估系统性**：在相同事件轨迹上改变披露策略，直接测量其对推断信号的影响，结果具有可比性和实用性。
- **自动语义层**：使用 LLM 生成广告话题和响应先验，提升了合成数据的表面真实性，同时保持标签和事件由模拟器控制，避免外部依赖。

## 8. 不足与局限

- **使用合成数据**：虽然通过公共数据校准，但仍为模拟环境，真实平台上的曝光/交互/披露行为可能差异显著。缺乏与真实广告系统的比照验证。
- **小规模实验**：8000 用户和 160 广告活动规模有限，无法评估大规模人口下的稀疏交互效应或组合攻击。
- **攻击评估受限**：监督攻击仅在合成数据上训练，若真实分布偏移则效果会下降；未考虑外部辅助知识（如数据经纪人信息）。
- **披露策略参数未充分探索**：阈值 \(k\)、随机披露概率 \(\rho\) 等仅取固定值，未进行敏感性分析。
- **未纳入广告拍卖/优化噪声**：模型假设曝光概率仅依赖谓词，未考虑竞价、用户价值等真实投放机制。
- **自适应攻击实用性存疑**：在真实平台上，广告主需花费真实预算，且平台可能限制广告频率；论文未模拟这些约束下的实际成本。
- **实验结果方差**：高交互设置下阈值穿越率标准差较大（0.158），可能暗示特定种子或话题下结果不稳定。
