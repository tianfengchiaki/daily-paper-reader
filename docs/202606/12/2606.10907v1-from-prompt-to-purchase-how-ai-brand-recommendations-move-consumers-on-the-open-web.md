## 摘要
当会话助手向近期无观察到的互动的用户推荐某个品牌时，该用户对同一品牌的谷歌搜索量上升了+4.3个百分点 [3.1, 5.5]，对该品牌自有网站的访问量上升了+2.4个百分点 [1.4, 3.5]，对品牌专属零售商页面的访问量上升了+1.0个百分点 [0.3, 1.7]——这一结果基于与匹配的后向安慰剂对照组的比较。得出这一估计需要细致的工作。提及品牌创造了曝光，但没有任何网络日志将此归因于助手，而看似衡量此效应的朴素全提及漏斗存在混杂：许多提及是对用户已使用品牌的附带引用（如“你的Netflix下载”），这些用户的下游访问是其作为现有客户的自发行为，表现为品牌特定的预趋势。我们通过一个面板测量平台外响应，该面板将自愿加入的点击流与这些用户的ChatGPT、Claude和Gemini对话相关联，并通过预趋势事件研究、立场分类器、非客户条件控制以及响应内同类别控制来分离效应：结果发现，附带提及对行为的影响要小得多（+1.8/+1.1/+0.3），而被提及品牌在相同响应中的表现远优于未提及的同类别品牌。下游路径主要通过搜索中介，并同时到达自有网站和零售商页面，其目的地组合追踪了品牌导向的基线行为，而非转向其中任一方向。本研究为观察性设计，且未观察交易，因此零售行为与购买接近。基于标准引荐来源和最后一次点击的测量方法会错过这种上游曝光：AI助手将明显未参与的用户沿着被归因于其他途径的路径引导到开放网络品牌导航中。

## Abstract
When a conversational assistant recommends a brand to a user with no recent observed engagement, that user's same-name Google search rises +4.3 percentage points (pp) [3.1, 5.5], visits to the brand's own site +2.4 pp [1.4, 3.5], and brand-specific retailer-page visits +1.0 pp [0.3, 1.7] over matched backward placebos. Recovering that estimate is the work. The mention creates a brand exposure no web log attributes to the assistant, and the naive all-mention funnel that seems to measure it is confounded: many mentions are incidental references to brands the user already uses ("your Netflix download"), whose downstream visits are that existing customer's own behavior and surface as a brand-specific pre-trend. We measure off-platform response on a panel that joins opt-in clickstream to the same users' ChatGPT, Claude, and Gemini conversations, and isolate the effect with a pre-trend event study, a stance classifier, non-customer conditioning, and a within-response same-category control: incidental name-drops then move behavior far less (+1.8/+1.1/+0.3), and the named brand moves far more than unnamed same-category brands in the same response. The downstream path is mostly search-mediated and reaches both own sites and retailer pages, with a destination mix that tracks baseline brand-directed behavior rather than redirecting toward either. The design is observational and we do not observe transactions, so retail is purchase-adjacent. Standard referrer-based and last-click measurement miss this upstream exposure: assistants move observably-unengaged users into open-web brand navigation along a path attributed elsewhere.

- **研究动机**：随着ChatGPT、Claude、Gemini等对话式AI助手在信息搜索中占据越来越大份额，它们会在回答中推荐品牌（如“跑表推荐：Garmin、Coros、Polar”），但这些品牌曝光无法被传统网络日志记录。标准的最后一次点击归因模型会将这些后续的谷歌搜索、品牌网站访问归因于自然搜索或直接访问，完全忽略了AI助手作为上游触达渠道的作用。因此，需要测量AI推荐对消费者行为的真实增量影响。
- **核心问题**：AI推荐是否真的能驱动消费者从提示走向购买路径（搜索→访问→零售页面）？如何从混杂的“全提及漏斗”中分离出真实的推荐效应？已有测量方法（如基于引用来源、最后一次点击）严重低估了这一影响。
- **整体含义**：该研究证明AI助手是一种未被记录的、可测量且显著的“上漏斗”营销触达，尤其对近期无品牌互动的用户（即“非客户”）有效，这对数字营销归因体系有根本性的重构意义。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：构建一个将用户自愿加入的点击流数据（页面级捕获）与同一用户的ChatGPT、Claude、Gemini会话记录相链接的测量面板。通过事件研究、立场分类、非客户条件控制、响应内同类别控制等观察性因果推断技术，分离出AI推荐的真实因果效应。

- **关键技术细节**：
  1. **数据单位**：每个分析单元为（用户，响应，品牌）三元组，针对跨品类品牌词表（高认知度、低同形歧义）衡量三个下游行为：
     - **召回**（Recall）：7天内对推荐品牌的谷歌搜索（查询含品牌名）。
     - **发现**（Discovery）：7天内访问品牌官网。
     - **零售**（Retail）：7天内访问品牌在零售商（如Amazon）的产品页面（通过URL路径识别品牌而非仅主机名）。
  2. **匹配后向安慰剂**：对每个曝光，以用户自身在响应前-14/-21/-28天等宽时间窗口的行为作为基线，计算提升量（差值）。公式：
     ```
     Δ_w = 1/|E| Σ_{(i,r,b)∈E} [Y(T_r, T_r+w) - 1/3 * Σ_{k∈{14,21,28}} Y(T_r-k, T_r-k+w)]
     ```
     其中Y为是否发生事件的0/1指标，w=7天。
  3. **立场分类**：使用小型语言模型将每个提及分为推荐（推荐）、中立（附带提及）、警告（谨慎）。推荐型挪动行为是中立型的2-3倍。
  4. **非客户条件控制**：定义“非客户”为用户在响应前窗口内无对该品牌的任何搜索、官网访问或零售页面访问（行为定义，非商业定义）。推荐的增量效应集中在此类用户。
  5. **响应内同类别控制**：在同一响应中，比较被推荐品牌与同类别但未被提及品牌的行为提升量。显著差异排除了一般意图激增或活动爆发等混杂。
  6. **无预先品类活动分层**：进一步限制用户在前一周无同品类任何词表品牌行为，保留92%样本，效应稳健。
  7. **事件研究（前趋势可视化）**：展示朴素全提及下品牌官网访问在响应前已上升（现有客户预趋势），而推荐×非客户则仅在响应后跳跃。

## 6. 论文的主要结论与发现

- **核心发现**：当AI助手向无近期观察互动的用户推荐品牌时，该品牌谷歌搜索提升4.3pp，官网访问提升2.4pp，零售商品牌页面访问提升1.0pp。效应2-3倍于附带提及。
- **效应集中**：效应主要发生在非客户（新触达），对现有客户（已有近期互动）未发现明显加速（仅与活跃期重合）。
- **路径特征**：下游行为主要通过搜索中介，而非点击助手内链接；自有网站和零售商页面为并行目的地，非严格顺序。
- **类别依赖性**：零售效应因品类而异（如美妆通过零售商，音频兼有自有和零售），单值零售效应无意义。
- **平台差异为人群差异**：ChatGPT效果大于Gemini，但用户内分析不显著，原因是ChatGPT用户本身更活跃（点击率更高），而非界面差异。
- **标准归因缺失**：几乎所有效应无法被最后一次点击模型捕获，因为上游曝光未被记录。

## 7. 优点：方法或实验设计上的亮点

- **创新性测量基础设施**：首次将自愿加入的点击流与LLM会话数据在用户级别链接，构建了可生产部署的测量层。

- **分解现有客户与新客户**：清晰表明助手的主要作用是“获取型触达”而非“强化现有客户”。

## 8. 不足与局限：包括实验覆盖、偏差风险、应用限制

- **观察性设计**：无法完全排除品牌特定的会话内意图冲击（即用户本来就要行动，同时促使助手指名）。作者明确承认这一点。
- **商业数据限制**：未披露面板规模、用户数量、品牌数量等，削弱了结果的可完全复现性和外部验证。
- **观察窗口与定义限制**：
  - “非客户”是行为定义（无近期观察互动），用户可能实际拥有但通过离线渠道购买。
  - 未观察交易（仅零售页面访问），不能直接推断购买。
  - 效应在7天内测量，长期影响未知。
  - 仅覆盖两个英语市场的高认知度品牌，长尾品牌未验证。
- **多重比较未校正**：多个假设检验（三个阶段、多种条件）的置信区间未做多重比较调整，虽然论文认为嵌套结构可辩护，但存在I类错误膨胀风险。

- **无传统归因方法数值对比**：论文仅逻辑论证标准归因会遗漏，未提供与last-click等方法的实际数值比较，对其实际量化影响尚不完整。
- **助手版本与时间范围**：数据截至2026年6月，AI模型快速迭代，结果可能随时间变化。
