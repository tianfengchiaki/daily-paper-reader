## 摘要
电商搜索中的查询推荐旨在主动建议与用户潜在兴趣匹配的查询。然而，现有方法主要优化查询级别的相关性，而忽略了检索到的商品是否与用户下游偏好一致。这种错位常导致高查询点击率（CTR）但低商品转化率（CVR）。为弥补这一差距，我们提出QueryAgent-R1，一种记忆增强的智能体框架，通过检索链优化改善端到端对齐。我们的QueryAgent-R1将查询生成基于真实库存检索，使智能体能够根据检索到的商品验证和优化查询。我们还在智能体强化学习（RL）过程中设计了一致性奖励，以联合优化查询相关性和下游参与度。此外，我们构建了记忆抽象模块以实现高效的用户画像。为支持离线评估，我们基于专有工业数据和公开数据集构建了两个数据集，QueryAgent-R1在这两个数据集上持续优于强基线。此外，在大型生产平台上，QueryAgent-R1在在线A/B测试中提升了2.9%的查询CTR和3.1%的引导CVR。

## Abstract
Query recommendation in e-commerce search aims to proactively suggest queries that match users' potential interests. However, existing methods mainly optimize query-level relevance, while neglecting whether the retrieved products align with users' downstream preferences. This mismatch often leads to high query click through rates (CTR) but low product conversion rates (CVR). To bridge this gap, we propose QueryAgent-R1, a memory-augmented agentic framework that improves end-to-end alignment via chain-of-retrieval optimization. Our QueryAgent-R1 grounds query generation in real inventory retrieval, allowing the agent to validate and refine queries based on retrieved products. We also design a consistency reward in the agentic reinforcement learning (RL) process to jointly optimize query relevance and downstream engagement. In addition, we construct a memory abstraction module for efficient user profiling. To support offline evaluation, we construct two datasets based on both proprietary industrial data and public datasets, on which QueryAgent-R1 consistently outperforms strong baselines. Moreover, on a large scale production platform, QueryAgent-R1 improves Query CTR by 2.9% and guided CVR by 3.1% in online A/B tests.

- **整体含义**：论文旨在通过将查询生成“接地”到真实商品检索，并引入一致性奖励的强化学习，从端到端弥合生成与检索的差距，最终提升电商查询推荐的业务价值（转化率与GMV）。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
提出 **QueryAgent-R1**，一种记忆增强的智能体（agentic）框架。核心是将查询生成过程与实时商品检索（product retrieval）耦合，通过多步“检索链”（chain-of-retrieval）优化，让智能体先生成查询、检索商品、验证结果并迭代优化，最后通过强化学习中的一致性奖励（consistency reward）联合优化查询相关性和下游商品交互。

### 关键技术细节

1. **记忆抽象机制（Memory Abstraction）**
   - 利用离线的大模型（Qwen3-Next-80B-A3B）异步压缩用户3个月的长周期行为日志（>10⁴ tokens）为紧凑的用户画像（包括最新意图、兴趣图、潜在身份、价格段等），实现约10倍压缩。
   - 在线部署时通过 `Fetch_Memory` 工具直接读取缓存画像，避免长上下文输入。

2. **商品检索增强（Product Retrieval Augmentation）**
   - 构建包含400万真实商品的检索沙箱（product sandbox），使用混合策略：BM25（稀疏检索）+ Qwen3-Embedding-0.6B（密集检索），再经Qwen3-Rerank-0.6B交叉编码器重排序。
   - 智能体在生成查询过程中可调用 `Product_Search` 工具观察返回商品，并根据结果调整查询，确保查询能检索到相关且可购买的商品。

3. **智能体强化学习训练（Agentic RL Training）**
   - 定义联合奖励函数：  
     \( R(y) = \lambda_{fmt} r_{fmt}(y) + \lambda_{tool} r_{tool}(y) + \lambda_{hit} r_{hit}(y) \)
     - `r_fmt`：格式正确性奖励；`r_tool`：工具调用正确性奖励；`r_hit`：查询-商品一致性奖励。
   - 进一步将 `r_hit` 分解为查询奖励和商品奖励，均包含稀疏（Exact Match / HitRate）和稠密（ROUGE）两部分，缓解奖励稀疏性。
   - 使用 **GDPO**（Group Reward-Decoupled Policy Optimization）优化策略模型，相比GRPO，GDPO对多奖励信号进行解耦归一化，更适合本场景。

### 算法流程（文字说明）
1. 输入用户实时行为序列（最近50个事件）。
2. 智能体调用 `Fetch_Memory` 获取用户长期画像。
3. 智能体生成候选查询，并调用 `Product_Search` 检索商品；若检索结果与用户后续点击商品不符，则迭代修改查询。
4. 输出最终推荐查询（用 `<next_query></next_query>` XML标签）。
5. 离线RL阶段：对每个输入采样K条轨迹，用GDPO根据上述奖励更新策略模型。

- **Cons@1**：两者同时成立，即端到端一致性
