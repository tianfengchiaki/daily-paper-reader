## 摘要
现代工业推荐系统使用深度排序模型，针对相同的用户和上下文特征对N个候选对象进行评分。标准实现会在前向传播早期广播上下文特征，每次请求冗余计算N次仅上下文相关的操作。我们提出了一种秩感知分解，适用于现代推荐架构中的主流交互机制——因子分解机（FM）成对乘积、深度交叉网络（DCNv2）交叉层、自注意力和全连接（FC）投影层——该分解基于单一代数原理：对秩划分输入进行的任何线性或双线性操作都允许精确的块分解，将仅上下文相关计算从每个候选对象一次转移到每个请求一次，且与原始模型恒等等价。闭式分析和受控消融实验表明，节省的计算量随上下文特征数量呈二次方增长。将该分解应用于生产级DLRM风格排序器而无需任何架构更改，在模型预测相同的情况下，每个Pod的吞吐量提高了87.5%（峰值Pod数量减少47%）。该恒等等价分解仅适用于交叉网络和自注意力的第一层，因为后续层在其输出中混合了不同秩。为了将节省扩展到深层，我们进一步引入了rDCN，一种DCNv2的架构变体，它在整个深度上保持秩规范，在总FLOPs减少67%的条件下，在训练噪声范围内匹配DCNv2的准确率，并简要概述了自注意力的类似架构变体。

## Abstract
Modern industrial recommender systems use a deep ranking model to score N candidates against the same user and context features. Standard implementations broadcast context features early in the forward pass, redundantly computing context-only operations N times per request. We present a rank-aware decomposition applicable to the dominant interaction mechanisms in modern recommender architectures-Factorization Machine (FM) pairwise products, Deep Cross Network (DCNv2) cross layers, self-attention, and fully connected (FC) projection layers-built on a single algebraic principle: any linear or bilinear operation over a rank-partitioned input admits an exact block decomposition that moves context-only computation from once-per-candidate to once-per-request, identity-equivalent to the original model. Closed-form analysis and controlled ablation verify that savings scale quadratically with the number of context features. Applied to a production DLRM-style ranker without any architectural change, the decomposition increases per-pod throughput by 87.5% (a 47% reduction in peak pod count) at identical model predictions.   The identity-equivalent decomposition applies only at the first layer of cross networks and self-attention, since each layer mixes ranks in its output. To extend savings across depth, we further introduce rDCN, an architectural variant of DCNv2 that maintains rank discipline across depth and matches DCNv2 accuracy within training noise at 67% fewer total FLOPs, and sketch an analogous architectural variant for self-attention.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现代工业推荐系统在排序阶段需要对 **N个候选对象** 进行评分，而每个请求中的 **用户和上下文特征** 是相同的。标准实现会在前向传播早期将上下文特征广播到候选批次维度，导致仅涉及上下文字段的操作（如上下文-上下文交互、线性投影、注意力等）被重复计算 **N次**，造成严重计算冗余。
- **研究动机**：随着模型引入更丰富的特征交互（如成对乘积、交叉层、注意力）以及上下文特征数量（K）的增长，冗余计算量呈 **二次方增长**（O(K²)），直接转化为巨大的基础设施成本和延迟。
- **整体含义**：本文提出一种**秩感知分解**原理，将上下文-only计算从“每个候选一次”转移到“每个请求一次”，保持模型输出恒等等价，同时大幅降低计算开销。此外，针对深层网络中秩混合问题，提出架构变体rDCN，将秩规范扩展到整个深度。

## 2. 论文提出的方法论

### 核心思想
- **秩感知分解原则**：任何线性或双线性操作，当输入按秩划分为上下文部分（rank-2）和目标部分（rank-3）时，都可以精确地分解为块操作。上下文-only部分可预先计算一次（rank-2），目标相关部分按候选计算（rank-3），最终结果与原始实现恒等等价。

### 关键技术细节

#### a) FM交互分解（应用于DLRM、DeepFM等）
- 标准FM计算所有 (K+M) 个字段的两两内积。分解为：
  - **FM_ctx**：仅上下文-上下文内积（共 K(K-1)/2 个），rank-2，每个请求计算一次。
  - **FM_tgt**：包含目标-上下文和目标-目标内积，rank-3，每个候选计算一次。
- 实现：FM_ctx通过上下文内积矩阵上三角计算；FM_tgt通过一次**非对称矩阵乘法**实现。
- 节省 FLOPs：Δ = (N-1) · C(K,2) · D，随K二次增长。

#### b) FC层分解（线性情况）
- 输入 x = [x_c; x_t]，权重W分块为[W_c; W_t]。
- 计算 x_c W_c 一次（rank-2），广播后与 x_t W_t 相加，再通过非线性激活。
- 节省：Δ = (N-1) · |x_c| · U（U为隐藏单元数）。当x_c来自FM输出时，|x_c| = C(K,2)，节省也随K二次增长。

#### c) DCNv2交叉层分解（仅第一层）
- 第一层输入 x0 = [x_c0; x_t0]，Wx可分块为四个子矩阵。W_cc x_c0 和 W_tc x_c0 仅依赖于上下文，可计算一次。
- 缺点：此后各层输入混合了秩，无法继续分解。节省仅在第一层有效。

#### d) 自注意力分解（仅第一层）
- Q/K/V投影：W_Q E = W_Q,c E_c + W_Q,t E_t，上下文投影计算一次。
- 注意力矩阵具有块结构：Q_c K_c^T 块为rank-2，计算一次；其余块为rank-3。
- Softmax上下文部分可通过FlashAttention式块对数-和-指数技巧与目标部分组合。

#### e) rDCN（秩感知DCN架构变体）
- 为解决深层秩混合问题，设计**两个并行流**：
  - 上下文流（rank-2）：仅通过上下文-上下文交叉更新。
  - 目标流（rank-3）：读取上下文流，但禁止目标到上下文的耦合（移除W_ct块）。
- 公式：
  - 目标流：T_{l+1} = T0 ⊙ (W_ct_l c_l + W_t_l T_l + b_t_l) + T_l
  - 上下文流：c_{l+1} = c0 ⊙ (W_c_l c_l + b_c_l) + c_l
- 参数更少（减少D_c D_t），FLOPs显著降低（上下文驱动计算从O(N D²)降为O(D_c²)+O(N(D_t D_c + D_t²))）。

#### f) 秩感知注意力（草稿）
- 类似双流：上下文自注意力（rank-2）；目标锚定注意力（目标查询，上下文键/值和目标键/值）。
