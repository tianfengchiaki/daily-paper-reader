## 摘要
多模态序列推荐（MSR）融合文本与视觉信息以提升推荐质量。然而，近期研究与我们的实证分析表明，视觉特征往往未被充分利用，其贡献远低于文本信号。我们将此问题归因于两个因素：视觉表征学习不足（预训练编码器无法捕捉偏好相关线索）以及视觉-文本优化不平衡（文本特征主导学习过程）。为解决这些问题，我们提出REVEAL（通过个性化视觉提取与自适应学习教会多模态推荐模型“看”），这是一个即插即用框架，在不修改原始推荐主干的情况下增强视觉表征学习与跨模态优化。REVEAL包含反馈引导视觉提取（FVE），通过任务级反馈优化提示引导的视觉提取；以及自适应视觉学习（AVL），动态重加权视觉学习以缓解模态不平衡。在多个真实世界数据集与MSR主干上的实验表明，REVEAL一致地提升了推荐性能。进一步分析显示，这些提升源于训练过程中对偏好相关视觉区域的更有效关注以及更好的视觉利用。代码见https://github.com/YutongLi2024/REVEAL。

## Abstract
Multimodal sequential recommendation (MSR) incorporates textual and visual information to improve recommendation quality. However, recent studies and our empirical analysis show that visual features are often underutilized, thereby contributing far less than textual signals. We attribute this issue to two factors: insufficient visual representation learning (pretrained encoders fail to capture preference-relevant cues) and unbalanced visual-text optimization (textual features dominate the learning process). To address these issues, we propose Teach Multimodal Recommendation Model to See via Personalized Visual Extraction and Adaptive Learning (REVEAL), a plug-and-play framework that enhances visual representation learning and cross-modal optimization without modifying the original recommendation backbone. REVEAL consists of Feedback-Guided Visual Extraction (FVE), which refines prompt-guided visual extraction through task-level feedback, and Adaptive Visual Learning (AVL), which dynamically reweights visual learning to alleviate modality imbalance. Experiments on multiple real-world datasets and MSR backbones demonstrate that REVEAL consistently improves recommendation performance. Further analysis shows that these gains arise from more effective attention to preference-relevant visual regions and better visual utilization during training. The code is available at https://github.com/YutongLi2024/REVEAL.

## 2. 论文提出的方法论

### 2.1 核心思想
提出**REVEAL**框架，包含两个即插即用组件：
- **反馈引导视觉提取（FVE）**：利用推荐任务反馈（推荐结果与真实交互的对比）迭代优化输入到视觉语言模型（VLM）的文本提示，引导VLM关注偏好相关区域，无需微调VLM参数。
- **自适应视觉学习（AVL）**：通过梯度重加权动态调整视觉参数在反向传播中的贡献，缓解模态不平衡。

### 2.2 关键技术细节
- **FVE流程**（算法1）：
  1. 初始提示`Prompt_X`基于物品元数据（标题、类别）及用户评论高频关键词构建。
  2. 冻结的VLM（默认使用Qwen2.5-VL-7B）在提示指导下提取视觉嵌入`e_v_X`。
  3. MSR骨干利用`e_v_X`、ID嵌入、文本嵌入进行推荐，得到结果`Result_X`。
  4. “提示分析”阶段：VLM作为评估者，根据推荐结果、真实交互及评估指令`EvalInstr`，生成分析文本`Critic_X`，指出当前提示的缺陷（如过度关注通用外观而忽略偏好属性）。
  5. “提示更新”阶段：VLM基于`Critic_X`和当前提示生成优化后的提示`Prompt_(X+1)`。
  6. 该过程每完成一次完整的骨干训练后执行一次，循环`X_max`次（超参数）。
- **AVL流程**（公式推导）：
  1. 构造两个单模态输出：视觉单独（文本嵌入置零）得分`s_v`，文本单独（视觉嵌入置零）得分`s_t`。
  2. 计算对应单模态损失`L_v`和`L_t`（使用骨干原始损失函数）。
  3. 定义损失差`Δ_v = L_v - L_t`，并映射为缩放因子`r_v = exp(Δ_v)`。
  4. 维护历史平均损失`¯L_v`、`¯L_t`，计算参考差距`¯r_v = exp(¯L_v - ¯L_t)`。
  5. 当前校准系数`K_v = exp(α · (r_v - ¯r_v))`，其中α为超参数。
  6. 在反向传播中将视觉相关参数梯度乘以`K_v`：`∂L_rec/∂θ_v ← K_v · ∂L_rec/∂θ_v`。
  7. 更新时保持其他参数不变。

### 2.3 算法流程（文字说明）
- **训练阶段**：整体训练如算法2所示。外层循环为每次提示更新（FVE），内层为骨干训练（应用AVL）。先提取当前提示下的视觉嵌入，训练骨干至收敛（同时应用AVL），然后执行提示分析更新提示。重复直到达到最大循环数。

## 8. 不足与局限
- **训练成本高**：FVE需多次迭代VLM推理与提示更新，主要耗时来源，在Yelp上增加近19小时。对资源受限场景不友好。论文未探索更高效的替代（如轻量级提示搜索、蒸馏）。
- **精粒度待优化**：提示更新仅在每次完整骨干训练后进行，可能无法快速适应数据分布变化。更细粒度的稳定更新策略有待研究。
- **数据集覆盖有限**：仅使用亚马逊（产品）和Yelp（服务）两类数据集，未在短视频、新闻、多模态社交等场景验证。此外，亚马逊数据集用户交互长度较短（平均8~15），长序列场景未涉及。

- **未与最新方法对比**：未与2025/2026年新提出的多模态推荐器（如VL-CLIP、LLM-based recommender）对比，仅与2023-2025年初的方法对比。
- **骨干限制**：验证仅限于基于序列的推荐（SASRec、STOSA等），未涉及基于图的推荐（如LightGCN属于传统推荐但非MSR骨干），也未在基于语言模型的推荐上测试。
