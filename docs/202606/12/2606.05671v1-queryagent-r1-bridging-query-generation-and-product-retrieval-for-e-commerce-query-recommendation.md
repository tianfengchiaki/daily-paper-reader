## 摘要
电商搜索中的查询推荐旨在主动建议与用户潜在兴趣匹配的查询。然而，现有方法主要优化查询级相关性，而忽略了检索到的商品是否符合用户的下游偏好。这种不匹配通常导致高查询点击率（CTR）但低商品转化率（CVR）。为弥合这一差距，我们提出了QueryAgent-R1，一种记忆增强的智能体框架，通过检索链优化改善端到端对齐。我们的QueryAgent-R1将查询生成基于真实的库存检索，使智能体能够根据检索到的商品验证和细化查询。我们还在智能体强化学习（RL）过程中设计了一个一致性奖励，以联合优化查询相关性和下游参与度。此外，我们构建了一个记忆抽象模块用于高效的用户画像。为支持离线评估，我们基于专有工业数据和公开数据集构建了两个数据集，QueryAgent-R1在这些数据集上持续优于强基线。此外，在一个大规模生产平台上，在线A/B测试中，QueryAgent-R1将查询点击率提升了2.9%，引导转化率提升了3.1%。

## Abstract
Query recommendation in e-commerce search aims to proactively suggest queries that match users' potential interests. However, existing methods mainly optimize query-level relevance, while neglecting whether the retrieved products align with users' downstream preferences. This mismatch often leads to high query click through rates (CTR) but low product conversion rates (CVR). To bridge this gap, we propose QueryAgent-R1, a memory-augmented agentic framework that improves end-to-end alignment via chain-of-retrieval optimization. Our QueryAgent-R1 grounds query generation in real inventory retrieval, allowing the agent to validate and refine queries based on retrieved products. We also design a consistency reward in the agentic reinforcement learning (RL) process to jointly optimize query relevance and downstream engagement. In addition, we construct a memory abstraction module for efficient user profiling. To support offline evaluation, we construct two datasets based on both proprietary industrial data and public datasets, on which QueryAgent-R1 consistently outperforms strong baselines. Moreover, on a large scale production platform, QueryAgent-R1 improves Query CTR by 2.9% and guided CVR by 3.1% in online A/B tests.

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- 将查询推荐建模为一个**链式检索优化问题**，目标最大化两个跳跃的联合概率：Hop-1 的查询点击（Query CTR）和 Hop-2 的商品点击（Item CTR）。
- 使用智能体（agent）框架，让 LLM 在生成查询前先调用内存工具和商品检索工具，基于检索结果进行查询验证和迭代优化。

### 关键技术细节
1. **记忆抽象机制（Memory Abstraction Mechanism）**
   - 构建长期记忆库，包含用户三个月的行为历史（超过 10^4 token）。
   - 使用 Qwen3-Next-80B-A3B 离线异步压缩原始行为日志为紧凑的用户画像（包括最新意图、兴趣图、潜在身份等），实现 10× 序列压缩。
   - 智能体通过 `Fetch_Memory` 动作直接获取缓存的画像，避免过长上下文注入。

2. **商品检索增强（Product Retrieval Augmentation）**
   - 构建包含 400 万真实商品的检索沙箱，来自真实电商环境。
   - 采用 BM25（稀疏检索）与 Qwen3-Embedding-0.6B（稠密检索）的混合检索，后接 Cross-Encoder（Qwen3-Rerank-0.6B）重排序。
   - 智能体在生成查询后调用 `Product_Search` 工具，检查返回商品是否符合预期，若不满足则调整查询。

3. **智能体强化学习（Agentic RL Training）**
   - 使用 GDPO（Group Decoupled Policy Optimization）算法优化策略模型（Qwen3-4B）。
   - 奖励函数设计：
     - 格式奖励 r_fmt：输出格式是否正确。
     - 工具调用奖励 r_tool：内存和检索工具调用是否正确。
     - 命中奖励 r_hit：分解为查询奖励和商品奖励。
   - 查询奖励：r_q = ExactMatch(q, q*) + ROUGE(q, q*)（硬匹配 + 软监督）。
   - 商品奖励：r_i = HitRate(I(q), I*) + ROUGE(Title, Title*)（稀疏命中 + 标题级软监督）。
   - 整体奖励：R = λ_fmt * r_fmt + λ_tool * r_tool + λ_hit * r_hit。
   - GDPO 相比 GRPO 更适合多奖励信号场景，能解耦梯度，避免“跷跷板”效应。
