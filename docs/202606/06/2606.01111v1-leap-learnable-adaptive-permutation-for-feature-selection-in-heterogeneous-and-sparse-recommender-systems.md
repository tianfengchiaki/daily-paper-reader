## 摘要
现代工业推荐系统依赖数千种异构特征——从低维标量（如统计值）到高维嵌入（如用户ID嵌入、MLP表示）——以实现高精度预测。鉴于训练过程中巨大的计算成本，高效的特征选择至关重要。然而，现有方法面临三个主要瓶颈：(1) 它们通常假设特征维度统一或需要昂贵的映射到固定大小；(2) 它们难以处理极端稀疏性，其中大部分特征（例如99%以上）保持默认值；(3) 传统的基于排列的方法在大规模设置中计算代价高昂。为了解决这些挑战，我们提出LeAP（可学习自适应排列），一种新颖的、与模型无关的即插即用特征选择模块。LeAP将低效的随机排列过程转化为可学习机制，显著加速了特征重要性评估。此外，我们引入了一种针对异构维度和极端稀疏性定制的自适应正则化策略，使得在非对称输入空间上获得更优的特征重要性排序结果。在四个公开推荐数据集上的实验表明，LeAP达到了最先进的性能。此外，LeAP已部署在一个大规模工业搜索排序模型中，该模型每日请求超过十亿，模型参数规模达2TB。在这个包含超过12,000个总特征维度的真实场景中，LeAP成功识别并移除了超过3,600个冗余维度且性能未下降，其能力是比较基线方法的2到10倍。

## Abstract
Modern industrial recommender systems rely on thousands of heterogeneous features -- ranging from low-dimensional scalars (e.g., statistical value) to high-dimensional embeddings (e.g., user-id embeddings, MLP representations) -- to achieve high-precision predictions. Given the immense computational costs associated with training, efficient feature selection is critical. However, existing methods encounter three primary bottlenecks: (1) they typically assume uniform feature dimensions or require costly mapping to a fixed size; (2) they struggle with extreme sparsity, where the majority of features (e.g., 99%+) remain at default values; and (3) traditional permutation-based approaches are computationally prohibitive in large-scale settings.   To address these challenges, we propose LeAP (Learnable Adaptive Permutation), a novel, model-agnostic plug-in module for feature selection. LeAP transforms the inefficient random permutation process into a learnable mechanism, significantly accelerating the evaluation of feature importance. In addition, we introduce an adaptive regularization strategy tailored for heterogeneous dimensions and extreme sparsity, enabling superior feature importance ranking results across asymmetric input spaces. Experiments on four public recommendation datasets demonstrate that LeAP achieves state-of-the-art performance. Furthermore, LeAP has been deployed in a large-scale industrial search ranking model with over a billion daily requests and a 2TB model parameter scale. In this real-world scenario involving 12,000+ total feature dimensions, LeAP successfully identified and removed over 3,600 redundant dimensions without performance degradation, which is 2 to 10 times the ability of compared baseline methods.

## 1. 论文的核心问题与整体含义（研究动机和背景）

现代工业推荐系统中，模型输入往往包含数千个异构特征：既有低维标量（如统计值），又有高维嵌入（如用户ID嵌入、MLP表示）。这些特征维度差异悬殊（从1维到256维不等），且存在极端稀疏性（超过99%的样本中特征保持默认值）。训练如此庞大的模型（参数规模可达TB级）需要巨大的计算和存储成本。因此，高效的特征选择成为关键。

现有特征选择方法面临三大瓶颈：
- **维度异构性**：多数方法假设特征维度统一，或强制将所有特征映射到相同维度空间，导致信息密度扭曲，难以公平评估1维与256维特征的真实贡献。
- **极端稀疏性**：稀疏特征由于“低频激活”常被误判为“无用噪声”而遭惩罚或丢弃，损害长尾个性化信号。
- **计算低效**：基于置换特征重要性（Permutation Feature Importance）的方法虽具可解释性，但需逐特征置换并重复前向传播，对于数千特征的大模型，计算量不可承受。

本文提出 **LeAP（Learnable Adaptive Permutation）**，一种模型无关的即插即用特征选择模块，旨在解决上述问题，实现高效、公平的特征重要性评估与冗余剔除。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
将传统离散、计算昂贵的置换评估转化为**端到端可学习机制**。通过一个动态门控网络学习原始特征与批级别置换噪声之间的融合权重，在一次前向传播中完成特征重要性评估，将计算复杂度从 \(O(N \times \text{model overhead})\) 降至 \(O(1 \times \text{model overhead})\)。

### 关键技术细节

1. **可学习置换模块**：
   - 对每个特征 \(i\)，在训练时构建其批级别置换版本 \(x'_i\)（沿batch维度随机打乱，保持边际分布和稀疏模式）。
   - 引入可学习门控变量 \(g_i \in (0,1)\)，通过带温度 \(\tau\) 的 Sigmoid 参数化：\(g_i = \sigma(\theta_i / \tau)\)。
   - 融合输出：\(\tilde{x}_i = g_i \cdot x_i + (1 - g_i) \cdot \text{sg}(x'_i)\)，其中 \(\text{sg}\) 为停止梯度操作，防止噪声梯度干扰上游层。
   - \(g_i\) 直观反映模型对原始特征的依赖程度：\(g_i \to 1\) 表示信任原始特征，\(g_i \to 0\) 表示特征可被替换为噪声。

2. **自适应正则化（Permutation Divergence）**：
   - 计算每个特征原始值与置换值的L2范数差异（Permutation Divergence）：\(\Delta_i = \frac{1}{B}\sum_{b=1}^B \|x_i^{(b)} - x'^{(b)}_i\|_2\)。
   - 使用指数移动平均（EMA）平滑得到稳定统计量 \(\bar{\Delta}_i^{(t)} = \beta \bar{\Delta}_i^{(t-1)} + (1-\beta)\Delta_i^{(t)}\)。
   - 自适应正则化权重：\(\lambda_i = \alpha \cdot \bar{\Delta}_i\)。
   - 总损失：\(\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{task}} + \sum_{i=1}^F \lambda_i \cdot g_i\)。
   - **两种独特性质**：
     - **维度自适应**：高维特征（如128D）的置换差异天生较大，自动获得更强惩罚，抵消其在均匀正则化下的“隐藏”优势。
     - **稀疏感知**：极端稀疏特征置换后差异接近0，惩罚极小，避免因稀疏而被误删。

3. **理论保证**：
   - 推导出门控梯度与置换差异的自然比例关系，使自适应惩罚与任务梯度尺度对齐。
   - 定理证明：若特征信号强度 \(\Delta J = J(0)-J(1) > \lambda_i\)，门控将推向1；若特征冗余（\(\Delta J \approx 0\)），门控则推向0，实现自然极化。

4. **工业部署流程**：
   - 在特征拼接层后插入LeAP模块，在线数据流中训练，积累EMA统计量并更新门控变量。
   - 通过绝对阈值（如0.5）或比例排序进行硬剪枝。
   - 移除冗余特征和LeAP模块后，用小部分数据微调模型直接上线。
