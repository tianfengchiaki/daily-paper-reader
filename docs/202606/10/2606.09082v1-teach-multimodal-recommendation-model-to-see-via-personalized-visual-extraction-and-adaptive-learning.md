## 摘要
多模态序列推荐（MSR）融合文本和视觉信息以提升推荐质量。然而，近期研究及我们的实证分析表明，视觉特征常被低效利用，其贡献远小于文本信号。我们将此问题归因于两方面：视觉表示学习不足（预训练编码器无法捕捉偏好相关线索）以及视觉-文本优化失衡（文本特征主导学习过程）。为解决这些问题，我们提出REVEAL（通过个性化视觉提取与自适应学习教会多模态推荐模型'看见'）——一种即插即用框架，在不修改原始推荐骨干网络的情况下增强视觉表示学习与跨模态优化。REVEAL包含反馈引导的视觉提取（FVE），通过任务级反馈优化提示引导的视觉提取；以及自适应视觉学习（AVL），动态重加权视觉学习以缓解模态不平衡。在多个真实世界数据集和MSR骨干网络上的实验表明，REVEAL一致提升了推荐性能。进一步分析显示，这些提升源于训练过程中对偏好相关视觉区域的更有效关注以及更好的视觉利用。代码已开源：https://github.com/YutongLi2024/REVEAL。

## Abstract
Multimodal sequential recommendation (MSR) incorporates textual and visual information to improve recommendation quality. However, recent studies and our empirical analysis show that visual features are often underutilized, thereby contributing far less than textual signals. We attribute this issue to two factors: insufficient visual representation learning (pretrained encoders fail to capture preference-relevant cues) and unbalanced visual-text optimization (textual features dominate the learning process). To address these issues, we propose Teach Multimodal Recommendation Model to See via Personalized Visual Extraction and Adaptive Learning (REVEAL), a plug-and-play framework that enhances visual representation learning and cross-modal optimization without modifying the original recommendation backbone. REVEAL consists of Feedback-Guided Visual Extraction (FVE), which refines prompt-guided visual extraction through task-level feedback, and Adaptive Visual Learning (AVL), which dynamically reweights visual learning to alleviate modality imbalance. Experiments on multiple real-world datasets and MSR backbones demonstrate that REVEAL consistently improves recommendation performance. Further analysis shows that these gains arise from more effective attention to preference-relevant visual regions and better visual utilization during training. The code is available at https://github.com/YutongLi2024/REVEAL.

- **核心问题**：尽管视觉信息被认为是重要的，但现有MSR模型中，**视觉特征的贡献远小于文本特征**。消融实验表明，去掉视觉特征对性能影响甚微，而去掉文本特征则导致性能大幅下降。
- **问题成因**：

    - **视觉-文本优化失衡**：在联合训练中，信息更直接、噪声更少的文本模态主导了学习过程，导致关于视觉信号的梯度优化被抑制，视觉模态学习不充分。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出了一个名为 **REVEAL** 的即插即用框架，旨在“教会”推荐模型如何更有效地“看见”和利用视觉信息。它包含两个核心组件，无需修改原始推荐模型的骨干网络。
- **关键技术细节**：
    - **反馈引导视觉提取（FVE）**：旨在解决视觉表示与用户偏好对齐问题。它不直接微调视觉-语言模型（VLM），而是通过推荐任务的反馈，用文本形式迭代优化输入到VLM的**提示词**。
        1.  **初始化提示**：根据用户评论、物品元数据（标题、类别）构建初始提示，引导VLM关注特定属性。
        2.  **视觉编码与推荐**：将初始提示和物品图片输入冻结的VLM，得到视觉嵌入，再进行推荐得到结果。
        3.  **提示分析**：将推荐结果与真实交互对比，利用VLM生成批评性分析，指出当前提示为何未能提取到有效的偏好相关视觉特征（如“过于关注鞋子等通用区域，而忽略了用户评论中强调的紧身感”）。
        4.  **提示更新**：基于批评分析，使用VLM重写提示，使其更聚焦于与用户决策相关的视觉区域。这个过程循环执行，逐步优化提示词。
    - **自适应视觉学习（AVL）**：旨在缓解训练中的模态失衡。它通过梯度重加权机制，动态调整视觉相关参数的更新幅度。
        1.  **估计单模态贡献**：在每次训练迭代中，分别计算仅使用视觉模态和仅使用文本模态的推荐损失（L_v 和 L_t）。
        2.  **量化模态差距**：计算当前批次的视觉-文本损失差，并累加历史平均差距，得到一个反映视觉相对学习困难的指标。
        3.  **动态梯度校准**：基于当前差距和历史平均差距的偏差，计算一个缩放因子 K_v。如果当前视觉损失高于历史平均（即视觉表现相对更差），则 K_v > 1，放大视觉相关参数的梯度；反之，则抑制其更新。这确保了视觉模态在优化过程中得到更充分的关注。

- **数据集与场景**：

### 6. 论文的主要结论与发现

1.  **视觉模态的低贡献是“人为”而非“天生”**：现有模型未能以偏好感知和优化感知的方式利用视觉信息，而非视觉信息本身无用。
2.  **REVEAL 框架显著且一致地提升推荐性能**：无论在哪种MSR骨干网络或数据集上，REVEAL都能带来稳定且显著的性能增益，尤其在 NDCG（强调排序质量）指标上提升更明显。
3.  **FVE通过反馈优化视觉提取**：其通过任务反馈迭代优化VLM提示词，成功引导模型关注与用户偏好相关的细微视觉区域，而非全局或背景信息。
4.  **AVL通过动态梯度校准缓解模态失衡**：主动对视觉相关梯度进行加权，能有效提升训练过程中视觉信号的利用程度。
5.  **FVE和AVL互补增效**：两者联合使用的效果优于单独使用任一模块，表明它们分别解决了“提取”和“优化”两个不同维度的问题。

### 7. 优点

- **创新性强**：将文本提示优化思想引入视觉特征提取，以及将多模态学习中的梯度平衡策略与推荐任务有效结合，为解决视觉利用不足问题提供了新颖且有效的思路。
- **通用性高**：提出的REVEAL是一个**即插即用**的框架，不依赖特定骨干网络结构，能与多种现有MSR模型无缝集成，应用范围广。
- **实用性好**：所有额外计算开销（主要是FVE的VLM推理）均发生在**训练阶段**，不增加推理时的延迟和算力成本，对实际部署友好。
- **消融充分，分析有力**：通过详细的消融实验和案例分析（尤其是FVE的注意力热力图可视化），清晰地揭示了每个模块的工作原理和增益来源，论证过程严密。
- **开放可复现**：提供了完整的代码仓库，利于学术界进行验证和后续研究。

### 8. 不足与局限

- **显著的训练成本**：FVE模块的迭代优化过程（特别是VLM的多次推理）带来了非常高的训练开销，尤其是在大规模数据集上。论文也指出这是主要瓶颈。
- **超参数敏感性**：FVE的最佳循环次数和AVL的校准强度α 等超参数在不同数据集上存在差异，需要针对具体任务进行调优。
- **VLM依赖**：框架性能高度依赖所选VLM的视觉理解能力。虽然实验比较了几种模型，但未探索更轻量级或特定任务微调的VLM方案，以平衡成本与性能。
- **实验覆盖范围**：实验主要聚焦于序列推荐场景。其在其他推荐范式（如基于会话的推荐、图推荐）中的效果未得到验证。此外，仅对比了Qwen系列及其他少数VLM，未覆盖更广泛的如GPT-4V等商业模型。
- **潜在偏差风险**：FVE的提示词优化依赖于用户评论。对于评论稀少或评论内容无法准确反映偏好（如虚假/广告评论）的物品，提示词优化的效果可能受限，甚至引入噪声。
