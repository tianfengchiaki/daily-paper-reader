## 摘要
离站转化率（OCVR）预测是计算推荐系统中的一个重要排序问题。该任务呈现建模挑战：点击信号丰富且时间跨度短，而转化信号本质稀疏、延迟长且常无法归因。尽管存在这些统计差异，两种信号类型都必须为在严格服务延迟约束下运行的模型提供信息。先前的预训练方法通过一个单一、无差别的编码器统一应用于两种数据流来解决这种异质性。我们提出DUET（双用户嵌入变换器），该框架将用户行为数据显式划分为两个领域一致的数据流——点击和转化，并为每个数据流的统计特征预训练专门的变换器编码器：用于密集点击流的多层自注意力，以及用于稀疏转化流的交错交叉和自注意力。得到的互补嵌入由下游排序器共同使用，且不超过服务延迟预算。评估显示相对于最强基线，归一化熵（NE）降低高达0.38%，A/B测试显示OCVR预测准确率一致提升。

## Abstract
Offsite conversion rate (OCVR) prediction is an important ranking problem in computational recommendation systems. This task presents a modeling challenge: click signals are abundant and exhibit short temporal horizons, whereas conversion signals are inherently sparse, long-delayed, and frequently unattributed. Despite these statistical disparities, both signal types must inform models that operate within strict serving-latency constraints. Prior pre-training approaches address this heterogeneity with a single, undifferentiated encoder applied uniformly across both data streams. We propose DUET (Dual User Embedding Transformers), a framework that explicitly partitions user behavioral data into two domain-coherent streams -- clicks and conversions -- and pre-trains dedicated transformer encoders with architectures tailored to each stream's statistical characteristics: multi-layer self-attention for the dense click stream and interleaved cross- and self-attention for the sparse conversion stream. The resulting complementary embeddings are jointly consumed by a downstream ranker without exceeding serving-latency budgets. Evaluation demonstrates up to 0.38% normalized entropy (NE) reduction relative to the strongest baseline, and A/B test shows consistent improvements in OCVR prediction accuracy.

# 论文 DUET — Dual User Embedding Transformers for Offsite Conversion Prediction 详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **研究任务**：离站转化率（Offsite Conversion Rate, OCVR）预测——预测用户在与推荐项目交互后，在外部网站或应用上完成目标行动（如购买、注册）的概率。
- **核心挑战**：
  - 点击信号丰富、时间跨度短；转化信号稀疏、延迟长（数小时至数天）、且常因跨设备或cookie限制而无法归因。
  - 现有方法使用单一、无差别的编码器统一处理点击与转化数据，导致密集的点击信号主导，稀疏的转化模式被忽视。
  - 在线推理有严格延迟约束，使得高容量模型无法直接部署。
- **整体含义**：DUET旨在通过将行为数据显式划分为两个领域连贯的数据流，为每个流设计专用编码器预训练互补的用户嵌入，再以异步方式供下游排序器使用，从而在不超过服务延迟预算的前提下提升OCVR预测准确率。

## 2. 论文提出的方法论

### 核心思想
- 领域感知数据路由 + 流专用编码器架构 + 异步嵌入服务。
- 将预训练数据分为两个流：**CTR/站内转化流**（密集、短窗口）和**站外转化流**（稀疏、长窗口、含未归因事件）。
- 预训练两个专用编码器，分别产出 **ClickAUE**（点击注意力用户嵌入）和 **ConvAUE**（转化注意力用户嵌入），下游排序器冻结使用。

### 关键技术细节

#### 数据路由
- CTR/站内转化流：负样本降采样，保留所有正样本。
- OCVR流：不做降采样以保留数据量；引入未归因转化事件的合成数据作为弱监督，缓解稀疏性。

#### 输入表示
- 用户-目标对：用户侧包含事件序列特征（EBF，含时间戳、ID属性、语义ID等）和静态特征；目标侧通过DLRM非序列分支处理。
- 事件序列覆盖数月跨度的推荐互动、有机浏览、视频内容等。

#### 编码器骨干架构（共享DLRM结构）
- 序列分支处理EBF序列，通过事件塔（Event Tower）+ DCN用户摘要模块生成嵌入。
- 非序列分支处理目标侧和用户静态特征。
- 两个分支在过拱交互层融合用于预训练预测。

#### 注意力配置（流专用）
- **ClickAUN（点击-注意力上游网络）**：采用多层自注意力（基于LLaTTE），序列长度最大1000，2层自注意力，2个头，维度256。适合密集、短窗口的点击数据。
- **ConvAUN（转化-注意力上游网络）**：采用交错交叉-自注意力。先用静态特征作为查询，序列特征作为键值做交叉注意力（对稀疏数据提供隐式正则），再跟自注意力。序列长度最大200，1层（交叉+自注意力），8个头，维度128。适合稀疏、长延迟的转化数据。

#### 训练目标
- ClickAUN：多任务BCE损失，优化CTR和站内转化预测。
- ConvAUN：多任务BCE损失，优化归因和未归因的站外转化预测。

#### 下游整合与异步服务
- 冻结的 ClickAUE 和 ConvAUE 作为额外特征输入下游DLRM排序器，梯度不反向传播。
- 事件触发推理（ETI）：用户执行锚定动作时，异步运行前向计算生成嵌入，经SIDE量化压缩存储。
- 在线推理时从特征存储解码嵌入，通过可学习MLP投影后输入下游模型。

- DUET框架在6个下游模型上一致优于单嵌入和基线，整体NE相对降低 **0.38%**，恢复理论上限的75%。

- **异步服务基础设施**：ETI + SIDE量化压缩，实现复杂上游模型与严格延迟约束的解耦。
