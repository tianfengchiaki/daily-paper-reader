## 摘要
从源产品图像以及布局和视觉内容指令中制作产品展示网页，对于营销、广告和电子商务等领域具有重要的实际价值。直观上，该任务要求产品展示在视觉上严格一致，并高度遵循指令以联合生成可渲染的HTML代码。这些对可控性和指令遵循的要求与先进的多模态生成模型（如图像编辑模型和统一模型）的核心特性紧密相关。为此，本文引入ProductWebGen来系统性地基准测试这些模型的产品网页生成能力。我们组织了包含500个测试样本的ProductWebGen，涵盖13个产品类别；每个样本由源图像、视觉内容指令和网页指令组成。任务是生成一个包含多个一致图像的产品展示网页，这些图像需与源图像和指令保持一致。鉴于任务的混合模态输入输出特性，我们设计并系统性地比较了两种评估工作流——一种使用大型语言模型和图像编辑模型分别生成HTML代码和图像（基于编辑），另一种依赖单一统一模型生成两者，其中图像生成基于先前的多模态上下文（基于统一模型）。实验结果表明，基于编辑的方法在网页指令遵循和内容吸引力方面取得领先结果，而基于统一模型的方法在完成视觉内容指令方面可能显示出更多优势。我们还构建了一个监督微调数据集ProductWebGen-1k，包含1000组真实产品图像和LLM生成的HTML代码。我们在开源统一模型BAGEL上验证了其有效性。数据和代码可在https://github.com/SJTU-DENG-Lab/ProductWebGen获取。

## Abstract
Crafting a product display webpage from a source product image, along with layout and visual content instructions, holds significant practical value for domains such as marketing, advertising, and E-commerce. Intuitively, this task demands strict visual consistency across product displays and high-fidelity instruction following to jointly generate renderable HTML code. These requirements on controllability and instruction-following are closely aligned with the core features of advanced multimodal generative models, such as image editing models and unified models. To this end, this paper introduces ProductWebGen to systematically benchmark the product webpage generation capacities of these models. We organize ProductWebGen with 500 test samples covering 13 product categories; each sample consists of a source image, a visual content instruction, and a webpage instruction. The task is to generate a product showcase webpage including multiple consistent images in accordance with the source image and instructions. Given the mixed-modality input-output nature of the task, we design and systematically compare two workflows for evaluation -- one uses large language models and image editing models to separately generate HTML code and images (editing-based), while the other relies on a single UM to generate both, with image generation conditioned on the preceding multimodal context (UM-based). Empirical results show that editing-based approaches achieve leading results in webpage instruction following and content appeal, while UM-based ones may display more advantages in fulfilling visual content instructions. We also construct a supervised fine-tuning dataset, ProductWebGen-1k, with 1,000 groups of real product images and LLM-generated HTML code. We verify its effectiveness on the open-source UM BAGEL. The data and code are available at https://github.com/SJTU-DENG-Lab/ProductWebGen.

## 2. 论文提出的方法论

- **核心思想**：将产品网页生成任务分解为两个子任务（HTML 代码生成 + 图像生成），并设计两种对比工作流。
- **关键技术细节**：
  - **编辑型工作流**：
    1. 使用 LLM 一次性生成完整的 HTML 代码，其中每个 `<img>` 标签的 `alt` 属性内嵌预期图像的详细文本描述。
    2. 将源图 + 文本描述输入图像编辑模型（如 Qwen-Image-Edit 或 FLUX.1-Kontext），对源图进行编辑以生成最终展示图像。
  - **基于统一模型（UM）的工作流**：
    1. 先让 UM 生成完整 HTML 代码，同样在 `alt` 中嵌入描述。
    2. 有两种图像生成方式：
       - **UM-based (HTML)**：将图像与之前生成的 HTML 代码交织上下文作为条件，生成图像。
       - **UM-based（默认）**：将图像与文本描述交织（避免长 HTML 干扰），生成图像。
  - **统一模型（UM）** 包括：BAGEL（采用混合 Transformer 专家架构）、Ovis-U1、OmniGen2、Gemini-2.5-Flash-Image。
- **评估指标（均基于 LLM-as-a-judge）**：
  - **Webpage Instruction Following (WIF)**：按子句检查 HTML 是否符合指令（0/1 平均）。
  - **Webpage Design Quality (WDQ)**：使用多模态 LLM 对截图打分（0-10），评估布局、色彩、视觉层次。
  - **Webpage Content Appeal (WCA)**：使用多模态 LLM 评估页面说服力（0-10），考虑促销语言、售后、评价等。
  - **Visual Content Instruction Following (VCIF)**：比较源图与生成图像，评估对视觉内容指令的遵循（0-10）。
  - **Image Perception Quality (IPQ)**：使用 VIEScore 方法，评估图像自然度（0-10）。

## 6. 论文的主要结论与发现

1. **总体最佳**：Gemini-2.5-Flash-Image（闭源 UM）在 VCIF 和 IPQ 上得分最高，网页指标也接近最优，展现出最均衡的能力。
2. **编辑型优势**：在网页指令遵循（WIF）、设计质量（WDQ）和内容吸引力（WCA）方面优于开源 UM，归因于其利用了更强的 LLM（如 Claude-Sonnet-4、Grok-4）进行 HTML 生成。
3. **UM 型优势**：在视觉内容指令遵循（VCIF）方面明显优于编辑型（+26.4%），因为其可以引用之前生成的图像作为上下文。
4. **开源 UM 与闭源 UM 的差距**：开源 UM（BAGEL、Ovis-U1、OmniGen2）在图像质量和 VCIF 上远落后于 Gemini-2.5-Flash-Image，部分原因是它们生成的 `alt` 文本长度不足（平均 20 词 vs 85 词），且随着图像生成顺序增加 IPQ 显著下降。
5. **HTML 上下文干扰**：UM-based (HTML) 设置中，复杂的 HTML 代码会削弱图像生成效果，VCIF 低于 UM-based（纯描述）设置。
6. **微调提升显著**：在 ProductWebGen-1k 上微调 BAGEL 后，VCIF 提升 22.3%（5.84→7.14），WIF 提升 65%（0.40→0.66），WDQ 和 WCA 也大幅上涨，超越编辑型的最佳组合。

  - 微调仅针对 BAGEL，未尝试其他开源 UM（如 Ovis-U1、OmniGen2），泛化性有限。
- **指标局限**：
  - VCIF 和 IPQ 使用 LLM-as-a-judge，可能忽略某些细微视觉差异（如文字可读性、边缘伪影）。

- **偏差风险**：
