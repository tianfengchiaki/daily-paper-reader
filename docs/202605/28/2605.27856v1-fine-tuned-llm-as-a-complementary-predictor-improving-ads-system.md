## 摘要
推荐系统驱动了信息流、广告和短视频平台的用户参与及变现，但将大语言模型的最新进展转化为推荐系统的实际收益仍然较为罕见，特别是在广告和工业级生产规模的真实场景中。先前大语言模型在现实中的成功通常分为三类：(a) 直接预测下一候选项目的生成式检索，(b) 利用大语言模型进行后期重排序，(c) 通过大语言模型进行辅助信号增强。我们为广告引入了一种互补范式：将微调后的开源大语言模型用作广告特定的辅助预测器（而非排序器），从用户画像和历史行为中预测可能的广告主。这种大语言模型驱动的广告主预测增强了传统的候选生成流程，并为下游排序提供了信息先验。在大规模生产广告系统中开发的方法带来了显著的离线改进和可衡量的在线业务影响，证明了大语言模型的世界知识和预测能力可以被高效利用。除了验证大语言模型在广告应用中的有效性，我们的结果表明，有针对性的辅助预测能够解锁检索和后期排序阶段的端到端收益，为大规模基于大语言模型增强的推荐系统提供了实用路径。

## Abstract
Recommendation systems power engagement and monetization across feeds, ads, and short-video platforms, but translating the latest advances in Large Language Models into Recommendation Systems (RecSys) gains remains rare, particularly in advertising and production-scale real-world industry setups. Prior real-world LLM successes typically fall into three buckets: (a) generative retrieval that directly predicts the next items for candidate generation, (b) late-stage re-ranking that uses LLMs, and (c) auxiliary signal enrichment with LLMs. We introduce a complementary paradigm for ads: a fine-tuned open-source LLM used not as a ranker, but as an ads-specific ancillary predictor, forecasting likely advertisers from user profiles and histories. This LLM-driven advertiser prediction augments conventional candidate generation and provides informative priors to downstream ranking. Developed in a large-scale production advertising system, our approach produces substantial offline improvements and measurable online business impact, demonstrating that LLM world knowledge and predictive capacity can be efficiently harnessed. Beyond validating LLMs for ads applications, our results show that targeted ancillary predictions can unlock end-to-end gains across both retrieval and late-stage ranking, offering a practical path to LLM-enhanced recommendation at scale.

# 论文总结：Fine-Tuned LLM as a Complementary Predictor Improving Ads System

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：推荐系统（RecSys）在信息流、广告和短视频平台中至关重要，但将大语言模型（LLM）直接融入工业级推荐系统面临三大障碍：
  1. LLM 难以处理稀疏的 ID 类特征（用户 ID、广告主 ID 等）。
  2. 工业推荐器依赖深层交叉特征和复杂校准目标，与 LLM 的文本语义不匹配。
  3. LLM 参数量大、推理延迟高，无法满足生产系统严格的尾延迟和成本约束。
- **现有 LLM 应用范式**：生成式检索（直接预测下一项目）、后期重排序（作为昂贵重排序器）、辅助信号增强（提取标签/特征）。但**在广告场景中展示大规模影响力的工作仍然稀少**。
- **核心含义**：提出一种**互补预测器范式**——将微调后的开源 LLM 用作广告特定的辅助预测器，**不替代现有检索/排序栈**，而是从用户信息中预测可能转化的广告主，从而增强候选生成和排序先验，实现检索和排序阶段的**端到端增益**。

## 2. 方法论：核心思想、关键技术细节与公式

### 核心思想
- 将 LLM **作为一个补充性的广告主预测器**，而非直接排序器。预测输出（广告主列表 + 用户兴趣）被用于：
  1. **检索阶段**：作为广告主导向的候选生成过滤器。
  2. **排序阶段**：作为下游转化模型（ctcvr, vtcvr）的输入特征。

### 关键技术细节

#### 数据流水线
- **用户选择**：限定为过去90天有活跃转化的美国 Pinterest 用户，平衡覆盖与推理成本。
- **标签构建**：预测窗口（第 x+1 至 x+7 天）内首个转化的广告主，用于“下一广告主”预测任务。
- **特征编译**：包括用户画像（年龄、性别、状态）和行为序列（站内搜索、站外转化、URL、类目、品牌等），以及活跃广告主池和预设广告主池。

#### 提示设计（三阶段）
| 阶段 | 预测目标 | 输出格式 |
|------|----------|----------|
| SFT | 单一下一广告主 | 自由文本 |
| GRPO | 排名前20的广告主 + 最多5个兴趣 | 结构化 XML |
| 推理 | 排名前20的广告主 + 最多5个兴趣 | 结构化 XML（同 GRPO） |

#### 后训练策略
1. **SFT（监督微调）**：在单广告主预测任务上训练，精确定位最可能的广告主。
2. **GRPO（基于组别相对策略优化）**：在 SFT 基础上，奖励函数鼓励正确广告主出现于列表并靠前排名，同时惩罚长度偏差。

**GRPO 奖励函数**：
\[
R_{\text{total}} = R_{\text{match}} - P_{\text{adv\_len}} - P_{\text{interest\_len}}
\]
其中：
\[
R_{\text{match}}(i) = 0.1 \times (20 - i) + \begin{cases}
2.0, & \text{if } i \le 4 \\
0, & \text{otherwise}
\end{cases}
\]
\[
P_{\text{len}}(n, n^*) = \begin{cases}
0, & \text{if } n = n^* \\
\min(0.1 \times |n - n^*|, 1.0) + 1.0, & \text{otherwise}
\end{cases}
\]

#### 语义 ID（SID）增强
- 通过多阶段持续预训练（CPT）+ 微调引入 SID 知识（基于 PinCLIP 的 RQ-VAE 编码）。
- 冻结/解冻策略，避免灾难性遗忘。

## 6. 主要结论与发现
1. **后训练至关重要**：所有微调变体均显著优于零样本提示，SFT + GRPO 在 V1 上 Recall@20 从 0.422 提升至 0.683。
2. **特征设计重要性**：活跃广告主（过去转化）是最关键特征；离站 URL 和搜索次之；用户画像贡献较小；部分类别特征有噪声（移除后 Recall@5 略微提升）。
3. **GRPO 优于纯 SFT**：GRPO 在扩大召回（大 K 指标）上表现突出，而 SFT 在精确定位（Recall@1）上更有效，两者结合最佳。
4. **语义 ID 增强有效**：引入 SID 后 Recall@1/5/20 分别提升约 10%+，提供多模态语义补充。
5. **下游模型提升**：LLM 预测广告主作为特征，使 ctcvr 的 PR-AUC 提升 0.71%，vtcvr 提升 1.64%。
6. **在线业务收益**：LLM 候选生成器使 U.S. Shopping 广告 RoAS 增加 **4.94%**（全体）和 **6.69%**（Opt-in 用户），且统计显著。

- **系统完整性**：从数据编译、提示设计、后训练到分布式部署、增量更新，覆盖全链路工业化细节。
