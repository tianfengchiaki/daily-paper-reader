## 摘要
微调大型语言模型（LLMs）已成为现代优化的核心应用，使预训练模型能够适应各种下游任务和特定领域数据。大规模微调中的一个主要障碍是反向传播的内存开销，这需要存储激活值、梯度和优化器状态。零阶（ZO）优化提供了一种节省内存的替代方案，但其性能对步长和平滑参数高度敏感，通常需要昂贵的任务特定调优。无参数（PF）优化通过在不预先知道问题相关常数的情况下自适应调整算法参数来解决这一问题。此外，大规模微调可以从考虑参数块异质结构的几何感知更新中受益，这可以通过利用线性最小化预言（LMO）的方法来建模。在这项工作中，我们研究了基于LMO的ZO优化的PF自适应，并引入了$\texttt{AdaNAGED}$，这是一种统一了无梯度训练、自适应调优和非欧几里得更新几何的方法。我们建立了收敛保证，并在$\texttt{OPT}-1.3\mathrm{B}$模型的大规模LLM微调任务上验证了该方法。

## Abstract
Fine-tuning large language models (LLMs) has become a central application of modern optimization, enabling pretrained models to adapt to diverse downstream tasks and domain-specific data. A major obstacle in large-scale fine-tuning is the memory overhead of backpropagation, which requires storing activations, gradients, and optimizer states. Zeroth-order (ZO) optimization offers a memory-efficient alternative, but its performance is highly sensitive to the stepsize and smoothing parameter, often requiring costly task-specific tuning. Parameter-free (PF) optimization addresses this issue by adapting algorithmic parameters without prior knowledge of problem-dependent constants. Moreover, large-scale fine-tuning can benefit from geometry-aware updates that account for the heterogeneous structure of parameter blocks, which can be modeled through methods that exploit linear minimization oracle (LMO). In this work, we study PF adaptation for LMO-based ZO optimization and introduce $\texttt{AdaNAGED}$, a method that unifies gradient-free training, adaptive tuning, and non-Euclidean update geometry. We establish convergence guarantees and validate the method on large-scale LLM fine-tuning task with $\texttt{OPT}-1.3\mathrm{B}$ model.

### 2. 论文提出的方法论

- **核心思想**：统一了三个互补的优化范式：
    1.  **零阶优化（Zeroth-Order, ZO）**：通过随机扰动下的函数值差分来估计梯度，大幅降低内存开销。
    2.  **无参数优化（Parameter-Free, PF）**：利用优化过程中的局部信息（如相邻点ZO梯度的差异）自适应地估计平滑常数和最优步长，无需人工调参。
    3.  **非欧几里得更新几何（Non-Euclidean Geometry）**：引入线性最小化预言（LMO），允许根据参数块的底层结构（如ℓ∞-范数对应SignSGD，谱范数对应Muon）定义更新方向，提升优化的效率。

- **关键技术细节**：
    - **无参数步长构建**：
        - **平滑常数（L）估计**：通过相邻迭代点的零阶梯度差分来**局部估计**平滑常数 $L_t$：$L_t = \frac{\|g_t(x_{t+1}, e_t) - g_t(x_t, e_t)\|_*}{\|x_{t+1} - x_t\|}$。该方法仅需存储随机种子，保持内存高效。
        - **自适应步长**：采用类似AdaGrad-Norm的方式，将累积的局部平滑估计求和作为步长的分母：$\gamma_t \propto \frac{1}{\sqrt{S_t}}, S_t = S_{t-1} + L_t$。步长分子由初始函数间隔 $\Delta = f(x_0) - \tilde{f}$ 确定。
    - **平滑参数（τ）的自适应缩放**：为了使局部平滑估计有界，平滑参数 $\tau_t$ 被设置为与步长 $\gamma_t$ 成线性关系：$\tau_t = \rho C_2 \gamma_t$。这避免了为 τ 进行单独调参。

- **算法流程**：
    论文提出了核心算法 `AdaNAGED`（Algorithm 1）和其矩阵版本的 `AdaMuGED`（Algorithm 2）。
    **`AdaNAGED` 算法流程描述**：
    1.  **初始化**：给定初始参数 $x_0$，初始化累积平滑常数 $S_{-1}$ 为极小值，初始步长 $\gamma_0$ 和平滑参数 $\tau_0$。
    2.  **迭代**（$t = 0$ 到 $T-1$）：
        a.  采样一个随机扰动方向 $e_t$（从二维球面）。
        b.  计算当前点的零阶梯度 $g_t(x_t, e_t)$。
        c.  通过 **LMO** 计算更新方向 $v_t = \text{lmo}(g_t(x_t, e_t))$。
        d.  **更新模型**：$x_{t+1} = x_t + \gamma_t v_t$。
        e.  在更新后的点上使用**相同的随机种子**计算零阶梯度 $g_t(x_{t+1}, e_t)$。
        f.  **估计局部平滑常数** $L_t = \frac{\|g_t(x_{t+1},e_t) - g_t(x_t,e_t)\|_*}{\|x_{t+1} - x_t\|}$（上标 * 代表对偶范数）。
        g.  **更新累积估计** $S_t = S_{t-1} + L_t$。
        h.  **自适应更新步长和** $\tau$：$\gamma_{t+1} \propto 1/\sqrt{S_t}, \tau_{t+1} = \rho C_2 \gamma_{t+1}$。
    3.  **输出**：最终的模型参数 $x_T$。
    - **`AdaMuGED` 的改进**：当选择谱范数和核范数（对应Muon类优化器）时，LMO的精确计算（SVD分解）代价高。论文使用**牛顿-舒尔茨迭代**（Newton-Schulz steps）来高效近似极分解（Polar operator），从而得到实用的 `AdaMuGED` 算法。

- **理论分析**：
    - 论文在凸、L-光滑、M-Lipschitz 假设下，证明了 `AdaNAGED` 的收敛率。虽然引入了由无参数估计导致的一些额外常数因子，但其主要项实现了与最优固定步长方案一致的 $O(1/\varepsilon^2)$ 渐近依赖关系。
