## 摘要
现代工业推荐系统使用深度排序模型来对N个候选物品与相同的用户和上下文特征进行评分。标准实现中，上下文特征在前向传播早期被广播，导致每个请求冗余计算N次仅依赖上下文的操作。我们提出了一种适用于现代推荐架构中主要交互机制（因子分解机（FM）成对乘积、深度交叉网络（DCNv2）交叉层、自注意力以及全连接（FC）投影层）的秩感知分解——该分解基于一个简单的代数原理：对于按秩划分的输入，任何线性或双线性操作都可以精确地进行块分解，将仅依赖上下文的计算从每个候选执行一次减少为每个请求执行一次，且与原模型恒等等价。闭式分析与受控消融实验验证，节省的计算量随上下文特征数量呈二次增长。将该分解应用于生产级DLRM风格排序模型（无需任何架构更改），在保持模型预测相同的情况下，每个pod的吞吐量提升了87.5%（峰值pod数量减少47%）。该恒等等价分解仅适用于交叉网络和自注意力的第一层，因为后续层的输出会混合不同秩的信息。为了将节省扩展到深层，我们进一步提出了rDCN，它是DCNv2的一种架构变体，在深度上保持秩的规则性，并在训练噪声范围内匹配DCNv2的精度，同时总FLOPs减少67%，并概述了自注意力的类似架构变体。

## Abstract
Modern industrial recommender systems use a deep ranking model to score N candidates against the same user and context features. Standard implementations broadcast context features early in the forward pass, redundantly computing context-only operations N times per request. We present a rank-aware decomposition applicable to the dominant interaction mechanisms in modern recommender architectures-Factorization Machine (FM) pairwise products, Deep Cross Network (DCNv2) cross layers, self-attention, and fully connected (FC) projection layers-built on a single algebraic principle: any linear or bilinear operation over a rank-partitioned input admits an exact block decomposition that moves context-only computation from once-per-candidate to once-per-request, identity-equivalent to the original model. Closed-form analysis and controlled ablation verify that savings scale quadratically with the number of context features. Applied to a production DLRM-style ranker without any architectural change, the decomposition increases per-pod throughput by 87.5% (a 47% reduction in peak pod count) at identical model predictions.   The identity-equivalent decomposition applies only at the first layer of cross networks and self-attention, since each layer mixes ranks in its output. To extend savings across depth, we further introduce rDCN, an architectural variant of DCNv2 that maintains rank discipline across depth and matches DCNv2 accuracy within training noise at 67% fewer total FLOPs, and sketch an analogous architectural variant for self-attention.

#### 1. 核心问题与整体含义（研究动机和背景）
- **问题**：工业推荐系统的深度排序模型需要为每个请求中的N个候选物品进行评分。标准实现中，用户和上下文特征（如用户画像、浏览历史等）对所有候选物品是相同的，但模型在前向传播早期会将上下文特征广播（tile）到候选维度，导致依赖上下文特征的计算（如上下文-上下文特征交互、全连接层投影等）被冗余执行N次，造成大量算力浪费。
- **背景**：现代排序架构（DLRM、DeepFM、DCNv2等）普遍在特征向量早期融合后进行计算。随着上下文特征数量K增长（如长用户历史、会话信号等），冗余计算的代价从线性（仅MLP）变为二次（交互层），加剧了服务成本与基础设施压力。
- **研究目标**：提出一种数学上精确（恒等等价）的分解方法，将涉及上下文特征的计算从“每个候选一次”迁移到“每个请求一次”，在不改变模型预测的前提下显著提升推理吞吐量；并进一步探索能贯穿整个深度的架构变体以扩大收益。

#### 2. 论文提出的方法论
- **核心思想**：**秩感知分解（Rank-Aware Decomposition）**。将输入特征划分为两个“秩”：上下文特征（秩-2，跨候选相同）和目标特征（秩-3，候选间不同）。任何线性或双线性操作都可以按块分解为“上下文-上下文”、“上下文-目标”、“目标-目标”部分，其中纯上下文部分可在请求级预计算一次。
- **关键技术细节**：
  - **线性操作（式1）**：\( Wx = W_c x_c + W_t x_t \)，其中 \( W_c x_c \) 只依赖上下文，计算一次。
  - **双线性操作（式2）**：\( x^T W y = x_c^T W_{cc} y_c + x_c^T W_{ct} y_t + x_t^T W_{tc} y_c + x_t^T W_{tt} y_t \)，同样 \( x_c^T W_{cc} y_c \) 一次计算。
  - **FM交互分解（表1）**：将FM输出拆分为 \( FM_{ctx} \)（上下文-上下文对，秩2，一次计算）和 \( FM_{tgt} \)（涉及至少一个目标的交互，秩3，每个候选计算）。公式（7）给出节省量：\( \Delta_{FM} = (N-1) \cdot \binom{K}{2} \cdot D \)，随K二次增长。
  - **FC层分解（式11）**：第一个FC层中 \( x_c W_c \) 一次计算，节省 \( (N-1) \cdot |x_c| \cdot U \)。当x_c来自FM_ctx时，同样随K二次增长。
  - **DCNv2交叉层分解（式14）**：只在第0层有效，因为后续层的输出混合了上下文和目标（秩混合），无法再分解。W_{cc}x_c0和W_{tc}x_c0可一次计算。
  - **自注意力分解（式17,18）**：Q/K/V投影可分解；注意力矩阵中的上下文-上下文块可一次计算，但softmax归一化需要行级别混合，可通过FlashAttention风格处理。
- **架构变体rDCN（§4.2）**：针对DCNv2深层无法分解的问题，提出保持秩纪律的并行双流设计：上下文流（秩2，纯上下文自身交叉）和目标流（秩3，包含上下文到目标的交叉W_{ct}c_l，但禁止目标到上下文的W_{ct}块）。公式（19-20）给出更新规则。它不再与原始DCNv2恒等，但精度相近，且FLOPs减少67%。
- **秩感知注意力（§4.3）**：类似双流设计，但仅在论文中概述，未在生产实现。
