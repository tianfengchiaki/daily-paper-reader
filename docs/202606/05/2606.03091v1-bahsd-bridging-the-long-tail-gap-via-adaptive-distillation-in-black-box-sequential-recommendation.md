## 摘要
序列推荐系统被广泛采用，但通常作为黑盒API部署，这推动了近期通过模型提取在本地复制其能力的研究。然而，长尾分布导致了严重的信号异质性：密集的头部序列触发教师偏好的固化，使提取偏向局部模式，而稀疏的尾部序列产生平坦且嘈杂的预测。现有的一刀切式提取忽视了这种差异，导致噪声过拟合和次优的知识迁移。我们提出BAHSD，一种黑盒自适应蒸馏框架，通过多尺度一致性探测机制隐式量化信号可靠性来处理信号异质性。在此基础上，设计了一种自适应分层目标：动态温度KL散度缓解高置信度信号的偏好固化，而排序一致性和InfoNCE对比学习为低置信度信号提供鲁棒增强。BAHSD始终优于基线，在教师模型上获得高达4.98%的提升，在尾部用户上获得80%以上的改进，为高保真黑盒推荐提取提供了一种即插即用的解决方案。

## Abstract
Sequential recommendation systems are widely adopted but often deployed as black-box APIs, which has driven recent interest in model extraction to replicate their capabilities locally. However, the long-tail distribution induces severe signal heterogeneity: dense head sequences trigger the solidification of teacher preference, biasing extraction toward local patterns, while sparse tail sequences yield flat, noisy predictions. Existing one-size-fits-all extraction overlooks this disparity, resulting in noise overfitting and suboptimal knowledge transfer. We propose BAHSD, a black-box adaptive distillation framework that handles signal heterogeneity via a multi-scale consistency probing mechanism to implicitly quantify signal reliability. Based on this, an adaptive hierarchical objective is designed: dynamic-temperature KL divergence mitigates preference solidification for high-confidence signals, while ranking consistency and InfoNCE contrastive learning provide noise-robust enhancement for low-confidence signals. BAHSD consistently outperforms baselines, achieving up to 4.98\% gain over the teacher and 80\%+ improvement on tail users, offering a plug-and-play solution for high-fidelity black-box recommendation extraction.

## 1. 核心问题与整体含义

- **研究动机**：序列推荐系统（SRS）在实际部署中常作为黑盒API（仅返回预测结果，隐藏内部参数与梯度），因此需要通过模型提取（black-box model extraction）在本地复制其能力。然而，用户交互呈长尾分布，导致教师模型的输出信号存在严重异质性：
  - **头部用户（head users）**：交互密集，教师输出分布过于尖锐（低熵），出现“偏好固化”，学生模仿时易继承局部偏置。
  - **尾部用户（tail users）**：交互稀疏，教师输出接近均匀分布（高熵），形成“信息真空”，学生易拟合噪声。
- **现有局限**：已有方法（如UnKD、RCE-KD）默认教师信号对所有用户一致可靠，采用一刀切蒸馏目标，无法适应这种异质性；而传统长尾去偏技术需要白盒访问（梯度/嵌入），在黑盒设置下不可用。
- **整体含义**：本文提出BAHSD，首个在严格黑盒约束下自适应处理信号异质性的蒸馏框架，仅依赖教师logits，通过多尺度一致性探测隐式量化信号可靠性，并设计自适应分层目标，实现高保真模型提取。

## 2. 方法论

### 核心思想
- 通过构造多尺度子序列（short, mid, full）探测教师输出，利用不同长度下输出的**一致性程度**隐式评估信号可靠性。
- 基于感知的可靠性，自适应切换蒸馏策略：
  - **高置信度信号（头部）**：采用**动态温度KL散度**，软化过尖峰分布，缓解偏好固化。
  - **低置信度信号（尾部）**：采用**排序一致性（BPR loss）+ InfoNCE对比学习**，替代激进的分布匹配，增强判别表示并抑制噪声。
- 引入**跨尺度对称KL一致性约束**，过滤尾部用户因稀疏数据产生的假性置信度，确保鲁棒性。

### 关键技术细节

#### 总体损失函数
\[
\mathcal{L}_{\text{total}} = \lambda_A \mathcal{L}_{\text{align}} + \lambda_B \mathcal{L}_{\text{inv}} + \lambda_C \mathcal{L}_{\text{cont}}
\]

#### 1. 多尺度语义对齐（\(\mathcal{L}_{\text{align}}\)）
- 对每个视图 \(p \in \{\text{short, mid, full}\}\)，联合BPR排序损失和温度缩放KL散度：
  \[
  \mathcal{L}_{\text{align}} = \sum_{p} \lambda_p \left[ \alpha \mathcal{L}_{\text{rank}}(z_T^p, z_S^p) + (1-\alpha) \tau_{\text{kd}}^2 \cdot \text{KL}(\sigma(z_T^p/\tau_{\text{kd}}) \| \sigma(z_S^p/\tau_{\text{kd}})) \right]
  \]
- 作用：全局温度 \(\tau_{\text{kd}}\) 自动适应信号质量——头部高熵暴露暗知识，KL主导；尾部低信号则KL梯度减弱，转向排序学习。

#### 2. 跨尺度不变性约束（\(\mathcal{L}_{\text{inv}}\)）
- 对称KL散度约束短、中视图的学生输出一致性：
  \[
  \mathcal{L}_{\text{inv}} = \frac{\tau_{\text{kd}}^2}{2} \left[ \text{KL}(p_S^{\text{short}}\|p_S^{\text{mid}}) + \text{KL}(p_S^{\text{mid}}\|p_S^{\text{short}}) \right]
  \]
- 作用：过滤尾部假置信度，保留真实意图平滑演化。

#### 3. 序列-项目潜在对比增强（\(\mathcal{L}_{\text{cont}}\)）
- 基于InfoNCE，以学生全序列表示 \(h_S^{\text{full}}\) 为锚点，教师logits top-1项目嵌入为正样本，均匀采样256个负样本：
  \[
  \mathcal{L}_{\text{cont}} = -\log \frac{\exp(\text{sim}(h_S^{\text{full}}, e_+)/\tau_{\text{cl}})}{\exp(\text{sim}(h_S^{\text{full}}, e_+)/\tau_{\text{cl}}) + \sum_{k=1}^{N_{\text{neg}}} \exp(\text{sim}(h_S^{\text{full}}, e_k^-)/\tau_{\text{cl}})}
  \]
- 作用：增大项目间距离，缓解头部表示坍塌；为尾部建立清晰决策边界。

### 算法流程
1. 对每个用户序列 \(S_u\)，生成短、中、全三个视图（按比例截取）。
2. 教师API返回各视图logits。
3. 学生模型分别处理三个视图，计算对齐损失 \(\mathcal{L}_{\text{align}}\)、不变性损失 \(\mathcal{L}_{\text{inv}}\)、对比损失 \(\mathcal{L}_{\text{cont}}\)。
4. 加权求和，端到端更新学生参数（无需用户分层或元数据）。
