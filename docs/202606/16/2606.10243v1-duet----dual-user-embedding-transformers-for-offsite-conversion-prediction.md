## 摘要
站外转化率（OCVR）预测是计算推荐系统中的一个重要排序问题。该任务面临建模挑战：点击信号丰富且时间跨度短，而转化信号本质稀疏、延迟长且常无法归因。尽管存在这些统计差异，两种信号类型都必须为在严格的在线服务延迟约束下运行的模型提供信息。先前的预训练方法通过一个单一的、无区别的编码器均匀地应用于两个数据流来解决这种异质性。我们提出DUET（双用户嵌入Transformer），该框架明确地将用户行为数据划分为两个领域一致的数据流——点击和转化——并针对每个数据流的统计特性预训练专用的Transformer编码器：对于密集的点击流采用多层自注意力，对于稀疏的转化流采用交叉注意力和自注意力交错的结构。生成的互补嵌入由下游排序器联合使用，且不超出在线服务延迟预算。评估表明，与最强基线相比，归一化熵（NE）最多降低0.38%，A/B测试显示OCVR预测精度持续提升。

## Abstract
Offsite conversion rate (OCVR) prediction is an important ranking problem in computational recommendation systems. This task presents a modeling challenge: click signals are abundant and exhibit short temporal horizons, whereas conversion signals are inherently sparse, long-delayed, and frequently unattributed. Despite these statistical disparities, both signal types must inform models that operate within strict serving-latency constraints. Prior pre-training approaches address this heterogeneity with a single, undifferentiated encoder applied uniformly across both data streams. We propose DUET (Dual User Embedding Transformers), a framework that explicitly partitions user behavioral data into two domain-coherent streams -- clicks and conversions -- and pre-trains dedicated transformer encoders with architectures tailored to each stream's statistical characteristics: multi-layer self-attention for the dense click stream and interleaved cross- and self-attention for the sparse conversion stream. The resulting complementary embeddings are jointly consumed by a downstream ranker without exceeding serving-latency budgets. Evaluation demonstrates up to 0.38% normalized entropy (NE) reduction relative to the strongest baseline, and A/B test shows consistent improvements in OCVR prediction accuracy.

## 1. 核心问题与整体含义（研究动机和背景）

- **任务定义**：站外转化率（Offsite Conversion Rate, OCVR）预测是指估计用户在宿主平台与推荐内容交互后，在外部网站或应用中完成目标动作（如购买、注册）的概率。
- **核心挑战**：点击信号丰富且具有短期归因窗口，而转化信号稀疏、延迟长（数小时到数天）且经常无法归因（unattributed）。两种信号统计特性差异巨大，但推荐模型必须同时利用它们，同时满足严格的在线服务延迟约束。
- **现有方法局限**：先前预训练方法使用单一、无差别的Transformer编码器统一处理点击和转化数据。这导致三个问题：
  1. **信号主导**：密集的点击信号主导训练，稀释稀疏的转化信号；
  2. **架构单一**：不同统计特性的数据流应当使用不同的归纳偏置（如注意力机制）；
  3. **跨域迁移浅**：仅依赖共享编码器或表示对齐，未充分利用有机交互和内容语义信号。
- **本文目标**：在不违反延迟预算的前提下，通过预训练互补的用户嵌入来提升OCVR预测精度。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **数据域划分**：将异构行为数据明确划分为两个领域一致的数据流——点击/站内转化流（CTR/Onsite-CVR）和站外转化流（OCVR）。
- **双流专用编码器**：对每个流预训练专用的Transformer编码器，架构匹配其统计特性。
- **异步服务集成**：生成的互补嵌入（ClickAUE和ConvAUE）被冻结作为静态特征供下游排序器联合使用，不增加在线推理计算开销。

### 2.2 关键技术细节

#### 数据路由（Domain-Aware Data Routing）
- **CTR/Onsite-CVR流**：包含点击和站内转化事件，标签窗口短。负样本降采样，正样本全部保留。
- **OCVR流**：包含站外转化事件，归因窗口长。不降采样以保留数据量；额外引入**合成数据**（synthetic data from unattributed conversions），即从无法归因的转化中推断最佳排序结果，提供弱监督信号缓解稀疏性。

#### 上游编码器设计（Upstream Encoder Design）
共享DLRM主干结构：
- **序列分支**：处理用户事件特征序列（Event-Based Features, EBFs），包含时间戳、ID属性、语义ID（Semantic IDs，来自图像/文本/视频的离散编码）。
- **非序列分支**：处理目标物品特征和用户静态特征。
- **融合层**：使用Deep & Cross Network (DCN) 生成最终用户嵌入。

**两个具体实例**：
- **ClickAUN（Click-Attentive Upstream Network）**：在CTR/Onsite-CVR流训练，输出ClickAUE。使用**多层自注意力**（基于LLaTTE范式），深堆叠捕获高阶交互。
- **ConvAUN（Conversion-Attentive Upstream Network）**：在OCVR流训练，输出ConvAUE。使用**交错的交叉注意力和自注意力**：静态特征查询序列特征（交叉注意力）以锚定表示，减少对长序列中多数负样本的过拟合，同时降低计算量。

#### 训练目标
- ClickAUN：多任务BCE损失，包含CTR和站内CVR任务。
- ConvAUN：多任务BCE损失，包含归因和未归因的站外转化任务。
- 任务权重通过验证集调优。

#### 下游集成（Downstream Integration）
- 下游排序器在标准特征基础上额外接收ClickAUE和ConvAUE作为输入嵌入。
- 嵌入在训练时冻结（不反向传播梯度），允许上游和下游独立更新。
- 服务时通过事件触发推理（Event-Triggered Inference, ETI）系统异步生成嵌入：当用户发生特定行为（如站内转化）时触发一次前向计算，结果经SIDE量化压缩后存入特征存储，在线推理时直接查找。

### 2.3 公式与流程（文字说明）
- 预训练阶段：数据流 → 域路由 → 专用编码器（自注意力/交叉注意力） → 多任务BCE损失优化 → 生成嵌入。
- 下游阶段：提取嵌入（压缩量化） → 作为特征加入下游模型 → 多任务损失（主OCVR + 辅助任务）训练。

## 6. 主要结论与发现

- **主结果**：DUET在最强基线上实现**0.38% NE降低**，理论上限（完全正交）为0.51%，回收约75%。ConvAUE单独贡献0.30%，ClickAUE单独贡献0.21%，组合产生**>13%相对提升**，说明互补性。
- **跨下游模型**：DUET在所有6个模型中一致优于单嵌入，但提升幅度差异显著（0.10%至0.36%），取决于现有特征集对点击/转化信号的覆盖程度。
- **消融发现**：
  - ConvAUE中**用户旅程事件**影响最大（PT NE退化0.30%，DR 0.1%）；合成数据贡献0.13% PT NE。
  - ClickAUE中**页面参与事件**最重要（0.07% PT），**序列/非序列架构缩放**贡献0.13% PT。
  - 稀疏转化流依赖少数高信号事件；密集点击流从广泛弱信号中获益。
- **在线A/B**：Ranker 3获得**+0.66% CVR提升**，Ranker 4获得**+0.15%**，均统计学显著。
- **延迟**：由于嵌入预计算和特征存储查找，在线推理延迟可忽略。

## 7. 优点

1. **方法创新性**：明确将行为数据划分为领域一致流，并为每个流设计匹配的注意力架构（自注意力 vs. 交叉-自注意力），优于单一编码器。
2. **理论与实验一致**：PCA和余弦距离分析显示嵌入正交/互补，解释了组合增益；定量达到理论上限的75%。
3. **工程实用性**：异步事件触发推理（ETI）+ SIDE量化压缩实现了4倍存储压缩且NE无损伤，在线延迟不增加。
4. **跨场景验证**：在6个不同下游模型和2个在线测试中均获一致提升，表明鲁棒性。
5. **弱监督利用**：合成未归因转化数据有效缓解稀疏性（消融证实贡献）。
6. **模块化设计**：上游和下游独立更新，便于维护和扩展。

## 8. 不足与局限

1. **数据路由规则化**：当前数据划分是静态、基于规则的；未来可学习路由实现更细粒度多流划分。
2. **注意力配置未全面比较**：只验证了当前分配（点击用自注意力，转化用交叉-自注意力），未与反向分配或两者混合作全面对比。
3. **冻结嵌入限制**：冻结嵌入简化训练解耦，但可能无法适应分布漂移；适应层（如adapter）或可缓解。
4. **可复现性有限**：实验完全基于Meta内部私有数据和广告系统，无法公开复现；未与学术界常见基线（如ESMM、MMoE、PLE）在公开数据集上对比。
5. **在线A/B测试范围小**：仅两个模型，未覆盖所有6个下游模型。
6. **合成数据噪声**：虽然提供弱监督，但合成数据方法本身可能引入噪声，其质量影响未深入分析。
7. **缺乏对延迟和吞吐的详细量化**：虽指出延迟可忽略，但未提供具体数据（如微秒级或QPS上限）。
