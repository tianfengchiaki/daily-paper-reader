## 摘要
当对话助手向近期无观察到的互动的用户推荐一个品牌时，该用户的同名谷歌搜索增加4.3个百分点（pp）[3.1, 5.5]，访问该品牌自身网站增加2.4 pp [1.4, 3.5]，品牌特定零售商页面访问增加1.0 pp [0.3, 1.7]，对比匹配的后向安慰剂。恢复这一估计是研究的关键。提及创造了品牌曝光，而任何网络日志均未将其归因于助手，且看似衡量这一点的朴素全提及漏斗存在混杂：许多提及是对用户已使用品牌的附带引用（如“你的Netflix下载”），其下游访问是现有客户自身行为，并表现为品牌特定的前趋势。我们通过一个面板测量平台外响应，该面板将选择加入的点击流与同一用户的ChatGPT、Claude和Gemini对话连接起来，并通过前趋势事件研究、立场分类器、非客户条件化以及同一响应中同类别控制来隔离效应：附带提及随后对行为的影响小得多（+1.8/+1.1/+0.3），且被提及的品牌在同一响应中的行为变化远大于未提及的同类别品牌。下游路径主要由搜索传导，并同时到达自有网站和零售商页面，其目的地组合跟踪了基线品牌导向行为，而非向任一方向重新定向。该设计为观察性研究，我们未观察到交易，因此零售是接近购买的行为。基于标准引荐来源和最后一次点击的测量忽略了这一上游曝光：助手将未观察到的未互动用户沿着归因于其他路径的轨迹导向开放网络品牌导航。

## Abstract
When a conversational assistant recommends a brand to a user with no recent observed engagement, that user's same-name Google search rises +4.3 percentage points (pp) [3.1, 5.5], visits to the brand's own site +2.4 pp [1.4, 3.5], and brand-specific retailer-page visits +1.0 pp [0.3, 1.7] over matched backward placebos. Recovering that estimate is the work. The mention creates a brand exposure no web log attributes to the assistant, and the naive all-mention funnel that seems to measure it is confounded: many mentions are incidental references to brands the user already uses ("your Netflix download"), whose downstream visits are that existing customer's own behavior and surface as a brand-specific pre-trend. We measure off-platform response on a panel that joins opt-in clickstream to the same users' ChatGPT, Claude, and Gemini conversations, and isolate the effect with a pre-trend event study, a stance classifier, non-customer conditioning, and a within-response same-category control: incidental name-drops then move behavior far less (+1.8/+1.1/+0.3), and the named brand moves far more than unnamed same-category brands in the same response. The downstream path is mostly search-mediated and reaches both own sites and retailer pages, with a destination mix that tracks baseline brand-directed behavior rather than redirecting toward either. The design is observational and we do not observe transactions, so retail is purchase-adjacent. Standard referrer-based and last-click measurement miss this upstream exposure: assistants move observably-unengaged users into open-web brand navigation along a path attributed elsewhere.

# 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：通过将用户选择加入的点击流数据与同一用户的ChatGPT、Claude、Gemini对话记录进行面板级链接，构建（用户、回复、品牌）三元组。采用匹配后向安慰剂设计（matched backward placebo），将回复后7天内的行为与回复前第14、21、28天相同长度的历史窗口进行差分，以获得非因果的对比基线。然后通过多个控制手段剥离混杂因素，提取出真正由AI推荐引起的增量效应。
- **关键技术细节**：
  - **单位**：每个观测单元是 (用户 i, 回复 r, 品牌 b)，品牌来自精心挑选的跨品类词汇表（高辨识度、低同形异义词歧义）。
  - **三个结局变量**：Recall（品牌回忆，用户在同名品牌Google搜索中出现查询）；Discovery（访问品牌自有网站）；Retail（访问零售商页面，且URL路径中明确识别出品牌，而非仅主机名）。
  - **基线对比**：对于每个三元组，计算结局在窗口 (T, T+w) 内的指示变量，并与三个后向安慰剂窗口 (T-14, T-14+w), (T-21, T-21+w), (T-28, T-28+w) 的均值进行差分。所有窗口宽度相同。公式：

  - **混杂控制**：
    - **立场分类器（stance classifier）**：用小语言模型将提及分为“推荐 / 中性 / 警告”，以区分真正推荐与附带提及（如“你可以在Samsung Pay使用”）。
    - **非客户条件化（non-customer conditioning）**：将用户定义为“无近期观察到的品牌参与”（过去数周内无搜索、自有网站、零售商访问），以剔除已有客户行为。
    - **同一回复内同品类对照**：在包含推荐品牌的同一回复中，找出未被提及的同类品牌作为对照，控制会话本身的品类意图和活动水平。
    - **事前趋势事件研究**：绘制推荐前后几天内的自有网站访问率，展示未控制混杂时事前趋势的存在，并通过非客户条件化消除。
  - **零售测量校正**：采用路径感知品牌匹配（path-aware matching，匹配URL路径而非仅主机名），否则零售效应会被低估近乎为零。对于本身就是零售商的品牌（Amazon、eBay等）单独处理。

# 6. 论文的主要结论与发现

- **主要结论**：AI对话助手的品牌推荐能显著推动无明显品牌参与历史的用户进入开放网络品牌导航，产生类似获客的效果。效应具体表现为：同名搜索 +4.3pp，自有网站访问 +2.4pp，零售商页面访问 +1.0pp。
- **辅助发现**：
  - 真正的推荐效应比附带提及大2-3倍（推荐 vs 中性：+4.3/+2.4/+1.0 vs +1.8/+1.1/+0.3）。
  - 效应集中在非客户身上；已有客户在推荐前后已经处于活跃品牌互动期，推荐只是伴随而非加速。
  - 效应是品牌特异的，同一回复内未提及的同品类品牌几乎无变化。
  - 下游路径以搜索为中介，而非直接点击助手内的链接（内嵌链接点击率极低）。
  - 目的地混合未显著偏移（自有网站与零售商比例与基线类似），表明AI推荐并未造成渠道替代。
  - 不同助手之间的表面差异主要源于用户组成（ChatGPT用户更活跃于Web），而非助手界面本身。
  - 未发现品牌熟悉度梯度（长尾效应不显著），也未发现提及位置效应（存在而非位置重要）。

# 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

- **观察性设计残余威胁**：无法完全排除“品牌特异会话内意图冲击”，即用户在相同会话中既出于自身意图搜索或购买某品牌，又恰好促使助手提及该品牌。尽管通过“无前期同品类活动”层有所缓解，但无法彻底消除，需随机或鼓励实验才能完全解决。
- **面板覆盖偏差**：选择加入的点击流面板可能不代表总体互联网用户，尤其是低web活跃度或隐私敏感用户。商业敏感信息未披露面板规模和人口统计，限制了外部有效性。
- **测量限制**：仅观察网页导航，无法观察应用内行为、离线购买、未记录渠道（如语音助手）。非客户定义基于近期无观测到的参与，不能排除用户已是品牌客户但通过其他渠道互动。零售仅测量页面访问，非实际交易，因此“购买相关”但非购买。
- **词汇表限制**：跨品类词汇表主要为高知名度品牌，对长尾/小众品牌仅通过三个单品类垂直和熟悉度梯度测试间接验证，但未直接测试极罕见提及的品牌。此外，仅覆盖两个英语市场，文化差异未考虑。
- **时间窗口选择**：7天效果窗口可能遗漏延迟行为；更短窗口（24h）效应较小，但7天可能包含多次互动。
- **立场分类器误差**：小模型分类器存在误差（Kappa=0.62），且倾向于将推荐误判为中性，导致推荐效应被保守估计。但作者认为这会使报告效应更保守。
- **多重比较问题**：未进行多重比较调整，但声称主要对比是预先指定的，且置信区间仅用于描述性。嵌套结构虽减轻问题，但仍值得关注。
- **商业敏感性**：许多关键细节（样本量、用户数、品牌列表等）未公开，降低了复现可能性。这一点是实际部署的合理限制，但对学术复现构成障碍。
