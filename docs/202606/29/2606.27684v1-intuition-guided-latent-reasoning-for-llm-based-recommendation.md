## 摘要
大型语言模型（LLMs）在复杂问题求解任务中展示了令人印象深刻的推理能力，这促使它们在推荐系统中用于偏好推理。潜在推理在连续隐藏空间而非离散令牌中运行，最近已成为基于LLM的推荐中一种有前途的范式。然而，现有方法通常从无约束的推理点开始，其中隐藏表示与目标物品嵌入未对齐，导致次优的推理轨迹。受认知神经科学的启发，该领域表明人类的多步推理由直觉作为潜在先验引导，我们提出了IntuRec，一个两阶段框架，将潜在推理锚定在推荐直觉上。在提取阶段，基于LLM的推荐器根据用户历史生成一个top-K候选集作为直觉的来源。在注入阶段，使用自注意力和交叉注意力机制将候选集转换为与偏好对齐的直觉嵌入，该嵌入初始化推理起点并指导后续的潜在推理。通过提供一个语义上有基础的起点，IntuRec沿着更准确的推理轨迹高效地探索偏好空间。在多个真实世界数据集上的大量实验表明，IntuRec持续优于最先进的基线。我们在https://github.com/Ten-Mao/IntuRec上发布代码。

## Abstract
Large Language Models (LLMs) have demonstrated impressive reasoning capabilities in complex problem-solving tasks, motivating their use for preference reasoning in recommender systems. Latent reasoning, which operates in continuous hidden spaces rather than discrete tokens, has recently emerged as a promising paradigm for LLM-based recommendation. However, existing methods often start from unconstrained reasoning points, where hidden representations are misaligned with target item embeddings, leading to suboptimal reasoning trajectories.   Inspired by cognitive neuroscience, which suggests that human multi-step reasoning is guided by intuition as a latent prior, we propose \emph{IntuRec}, a two-stage framework that anchors latent reasoning with \emph{recommendation intuition}. In the extraction stage, the LLM-based recommender generates a top-$K$ candidate set based on users' histories as the source of intuition. In the injection stage, the candidate set is transformed into a preference-aligned intuition embedding using self- and cross-attention mechanisms, which initializes the reasoning start point and guides subsequent latent reasoning. By providing a semantically grounded starting point, IntuRec efficiently explores the preference space along more accurate reasoning trajectories. Extensive experiments on multiple real-world datasets demonstrate that IntuRec consistently outperforms state-of-the-art baselines. We release our code at https://github.com/Ten-Mao/IntuRec.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有基于大型语言模型（LLM）的推荐系统中，**潜在推理（latent reasoning）** 方法通常从**无约束的推理起始点**开始，其隐藏表示与目标物品嵌入不一致，导致推理轨迹偏离最优区域，限制了推荐性能。
- **背景**：LLM 已展现出强大的推理能力，被用于推荐中的偏好推理。潜在推理在连续隐藏空间中进行多步推理，比链式思维（CoT）更高效，但现有方法缺乏对推理过程的显式引导。
- **研究动机**：受认知神经科学启发，人类多步推理由**直觉（intuition）** 作为潜在先验引导。论文提出将**推荐直觉**显式提取并注入 LLM 的潜在推理过程，以提供语义上更有依据的起始点，从而引导推理沿更准确的轨迹探索偏好空间。

### 2. 论文提出的方法论

- **核心思想**：提出 **IntuRec** 两阶段框架，模拟人类“先形成直觉，再推理”的过程。
- **关键技术细节**：
  - **阶段一：直觉源提取（Intuition Source Extraction, ISE）**
    - 训练一个基于 LLM 的推荐器（backbone）进行序列推荐（下一个物品预测）。
    - 推理时使用**束搜索**生成离线 top-K 候选列表 \(c^+\)，作为直觉源。
    - **目标感知候选平衡（Target-Aware Candidate Balancing, TACB）**：通过概率 \(\alpha\) 控制训练实例中候选列表是否包含真实目标物品，避免捷径学习。
  - **阶段二：直觉表示注入（Intuition Representation Injection, IRI）**
    - 使用**直觉双注意力编码器（Intuition Dual-Attention Encoder, IDAE）**：
      - 对每个候选物品的 token 序列执行**自注意力**，经最后 token 池化得到物品级表示。
      - 以初始推理状态 \(r_1\) 为 query，对所有候选物品表示执行**交叉注意力**，得到直觉嵌入 \(r_1^+\)，替换原始起始点。
    - **损失函数**：
      - 主损失：推荐损失 \(\mathcal{L}_{\text{rec}}\)（标准 next-token prediction）。
      - 辅助损失：直觉对齐损失 \(\mathcal{L}_{\text{intu}}\)（基于 BPR 的对比学习，使正例嵌入与目标物品嵌入相似，负例远离）。
      - 总损失：\(\mathcal{L}_{\text{IRI}} = \mathcal{L}_{\text{rec}} + \lambda \mathcal{L}_{\text{intu}}\)。
  - **训练流程**：两阶段交替训练，先优化 ISE 得到候选列表，再联合优化 IRU 阶段的 LLM 和 IDAE 参数。

### 6. 论文的主要结论与发现

- **性能提升**：IntuRec 在所有数据集上**一致优于**所有对比基线，其中 IntuRec-D 取得最佳结果。
- **消融有效性**：每个组件（TACB、IDAE 中的自注意力/交叉注意力、直觉对齐损失）均不可或缺，移除后性能下降。
- **初始化优势**：直觉嵌入（\(r_1^+\)）的嵌入空间分布比无约束的起始点更接近目标物品，且呈现**各向异性的紧凑偏好子空间**，可作为“指南针”高效引导推理。
- **超参数结论**：\(K=15\) 时性能峰值；\(N=1\) 即最佳，更多推理步数带来轻微下降，说明高质量起始点能显著减少推理深度需求。
- **候选来源**：使用 LLM 自身生成候选列表优于传统模型（如 SASRec），说明直觉源与推理架构对齐的重要性。
- **效率**：IntuRec 推理速度比 LatentR³ 更快（仅需在第一步进行直觉聚合），训练虽更慢但值得。

### 7. 优点

- **问题新颖性**：首次从认知科学角度引入“推荐直觉”概念，为潜在推理提供显式先验，填补了推理起始点无约束的空白。
- **框架清晰有效**：两阶段设计（ISE + IRI）逻辑自洽，TACB 机制巧妙抑制捷径学习；IDAE 架构通过自注意力+交叉注意力实现紧凑的直觉编码。
- **实验设计全面**：涵盖多个数据集、多种基线、丰富消融、可视化、效率分析等，验证充分。
- **开源代码**：提供 GitHub 仓库，可复现性强。

### 8. 不足与局限

- **实验覆盖**：仅基于 **Qwen2.5-1.5B** 一个 backbone 模型，未测试更大模型（如 7B/70B）或更广泛的数据集（如工业级大规模数据）。推测在小模型上已验证，但在更大模型上的扩展性待确认。
- **偏差风险**：候选列表由同一 LLM 在 ISE 阶段生成，可能引入回声偏差（模型倾向选择已经熟悉的候选）。TACB 虽缓解一部分，但未完全消除。
- **应用限制**：当前仅针对**序列推荐**任务，对其他推荐类型（如社交推荐、会话推荐、特征交叉推荐）的适用性未知。此外，需存储离线候选列表，增加存储开销。
- **资源消耗**：训练时需两阶段（ISE + IRI），且需计算并更新候选列表，训练时间较长（附录表 8 显示训练步时比 BIGRec 高约 74%）。
- **推理深度**：最优推理步数 \(N=1\) 表明直觉嵌入已足够强，但该结论是否通用？对于更长、更复杂的用户序列可能需要更多步，论文未深入探讨。
- **对比先进方法**：未与近期强化学习引导的推理方法（如 DeepSeek-R1 风格）对比，尽管 RecLLM-R1 等被提及，但未作为基线。
