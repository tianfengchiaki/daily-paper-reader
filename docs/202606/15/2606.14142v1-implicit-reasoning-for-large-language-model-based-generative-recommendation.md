## 摘要
大语言模型（LLMs）越来越多地被用作生成式推荐（GR）的骨干模型，有望利用预训练的世界知识。然而，如何可靠地调用这些知识用于GR仍是一个未解之谜。一个关键障碍是，基于LLM的GR通常使用语义ID（SIDs）表示项目，这破坏了LLM的自然语言推理接口，因为这些标记在预训练期间LLM从未见过。现有方法通过昂贵的多阶段流水线来应对这一问题，这些流水线将SID与显式推理过程对齐，但对每个阶段何时以及为何必要提供的洞察有限。在这项工作中，我们系统地分解了基于LLM的GR的显式推理训练流水线，揭示了三个关键局限：世界知识语言化能力减弱、SID与自然语言标记嵌入空间之间的错位、以及对推理质量敏感，所有这些都损害了显式推理性能。为了规避这些问题，我们提出了PauseRec，一种轻量级的隐式推理范式，专为GR设计。PauseRec非常实用，避免了昂贵的推理轨迹获取和推理对齐训练，带来了多重好处：（1）性能比标准显式CoT方法高出最多6.22%，（2）训练成本降低最多65% GPU小时，（3）推理速度提升最多71.3%。这些结果使PauseRec成为显式推理生成的一种轻量级替代方案，实现了更有效和高效的基于LLM的GR。

## Abstract
Large Language Models (LLMs) are increasingly adopted as backbones for Generative Recommendation (GR), promising access to pretrained world knowledge. Yet reliably invoking this knowledge for GR remains poorly understood. A key obstacle is that LLM-based GR typically represents items with Semantic IDs (SIDs), disrupting LLMs' natural-language reasoning interface because these tokens are unseen by the LLM during pretraining. Existing approaches address this with expensive multi-stage pipelines that ground SIDs and elicit explicit rationales, but offer limited insight into when and why each stage is necessary. In this work, we systematically decompose explicit reasoning training pipelines for LLM-based GR, revealing three key limitations: weakened world-knowledge verbalization, misalignment between SID and natural-language token embedding spaces, and sensitivity to rationale quality, all of which hurt explicit reasoning performance. To circumvent these issues, we propose PauseRec, a lightweight implicit reasoning paradigm tailored for GR. PauseRec is exceptionally practical, avoiding costly reasoning trace acquisition and reasoning alignment training, leading to a multitude of benefits: (1) it outperforms standard explicit CoT methods by up to 6.22%, (2) it reduces training cost by up to 65% GPU hours, and (3) it speeds up inference by up to 71.3%. These results position PauseRec as a lightweight alternative to explicit rationale generation, enabling more effective and efficient LLM-based GR.

## 6. 论文的主要结论与发现

1. **显式 CoT 在 SID-based GR 中效果有限**：各种理由变体（模板式、教师生成、拒绝采样等）均未超过简单的 next‑item SFT，只有在昂贵的 RL 后训练后才能获得收益。
2. **显式推理失败的三原因**：
   - **知识语言化困难**：CoT SFT 后模型的世界知识仍保存在 logit 空间，但难以通过自然语言文本解码出来（表3）。
   - **文本–SID 嵌入空间不对齐**：训练过程中 SID 嵌入逐渐远离自然语言嵌入，导致通过自然语言理由影响 SID logits 的能力受限（图2、定理1）。
   - **理由敏感性**：微小扰动（如删除目标类别、随机增减 5 个词）都能显著降低推荐性能（表4）。
3. **PauseRec 的有效性与效率**：
   - 在三个数据集上，PauseRec 在 10/12 指标上超越含 RL 的 OneRec‑Think（提升最高 6.22%），并在所有指标上优于 next‑item SFT。
   - 训练 GPU 小时减少 65%，推理速度提升 3.5 倍。
4. **隐式推理的工作机制**：注意力分析显示，早期 pause 关注全局指令和历史边界，中期和后期逐步聚焦于与目标相关的历史 SID，实现了类似 CoT 的阶段性推理，但无需显式文本。

## 7. 优点

- **新颖的问题分析**：首次系统诊断显式推理在 SID‑based GR 中的失败机制，提供理论证明和可视化证据。
- **轻量高效**：PauseRec 避免昂贵的理由采集和 RL 训练，在提升性能的同时大幅降低计算成本，实用性极强。
- **方法简洁**：仅添加一个可训练的 `<pause>` token 和两阶段训练（预训练 + 隐式 SFT），易于集成到现有 GR 管道。
- **可解释性**：通过注意力可视化揭示了隐式推理的多阶段过程，有助于理解模型行为。
- **实验全面**：涵盖性能、效率、诊断、消融、参数分析、定性分析等多个层面，结论可靠。

## 8. 不足与局限

- **离线评估**：仅使用标准离线 next‑item 预测协议，缺少用户感知研究（如多样性、新颖性、用户接受度）。
- **数据集范围有限**：仅使用 Amazon 三个垂直领域（美妆、运动、玩具），未测试新闻、视频、社交等场景，且物品数量在万级，对更大规模的支持需验证。
- **pause 数量未完全优化**：只实验了 k={1,3,5,10}，未尝试更精细的搜索或可变长度 pause；pause 插入位置和初始化方式也有改进空间。
- **缺乏统计显著性报告**：主实验未提供多次运行的标准差或置信区间，难以判断改进的统计显著性。
- **隐含偏差风险**：如同其他推荐系统，可能放大流行偏差、加固用户历史偏好，或继承 LLM 预训练数据中的偏见。
- **中间计算不可读**：隐式 `<pause>` token 不是自然语言，用户难以直接理解推荐理由，可能需要额外的解释模块。
- **RL 后训练未完全排除**：论文声称 PauseRec 完全避免 RL，但仅在当前配置下对比；不排除在更大模型或不同数据上结合轻量 RL 可能进一步改进。
