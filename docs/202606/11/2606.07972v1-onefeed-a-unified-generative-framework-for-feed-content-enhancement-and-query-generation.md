## 摘要
现代Feed推荐与搜索系统在用户行为上紧密关联，但通常由独立架构分别建模。Feed推荐主要从浏览交互中捕捉隐式兴趣，而搜索系统依赖显式用户查询来检索意图匹配的内容。这种分离导致用户理解碎片化，并错过利用Feed交互改进查询生成以及利用生成查询增强Feed候选检索的机会。本文提出OneFeed，一个联合建模Feed内容增强与查询生成的统一生成式框架。OneFeed通过共享行为编码器对异构用户行为序列进行编码，并采用两个生成头：用于推荐检索的内容语义ID生成器（Feed Semantic ID Generator）和用于基于搜索的候选扩展的自然语言查询生成器（Intent Query Generator）。为弥合推荐内容与搜索查询之间的语义鸿沟，我们引入语义ID-查询对齐目标，学习内容语义ID与查询表征的共享语义空间。我们进一步设计闭环自增强范式，利用来自生成内容与搜索检索结果的隐式用户反馈改进两个生成任务。我们使用弱监督查询构建的公开推荐数据集提供详细实验协议，定义全面评估指标，报告基于已知基准值的预期性能估计，并通过最小本地原型验证所提管线的可执行性。OneFeed为通过生成式建模统一搜索与推荐提供了实用且可扩展的方向。

## Abstract
Modern feed recommendation and search systems are deeply connected in user behavior butare usually modeled by separate architectures. Feed recommendation mainly captures implicitinterests from browsing interactions, while search systems rely on explicit user queries to retrieveintent-matched content. This separation causes fragmented user understanding and missedopportunities for using feed interactions to improve query generation and using generated queriesto enhance feed candidate retrieval.In this paper, we propose OneFeed, a unified generative framework for jointly modelingfeed content enhancement and query generation. OneFeed encodes heterogeneous user behaviorsequences with a shared behavior encoder and employs two generative heads: a Feed SemanticID Generator that produces content semantic IDs for recommendation retrieval, and an IntentQuery Generator that produces natural-language queries for search-based candidate expansion.To bridge the semantic gap between recommendation content and search queries, we introduce aSID-Query alignment objective that learns a shared semantic space for content semantic IDs andquery representations. We further design a closed-loop self-enhancement paradigm that leveragesimplicit user feedback from generated content and search-retrieved results to improve bothgeneration tasks. We provide a detailed experimental protocol using public recommendationdatasets with weakly supervised query construction, define a comprehensive set of evaluationmetrics, report expected performance estimates grounded in known baseline values, and validatethe executability of the proposed pipeline through a minimal local prototype. OneFeed providesa practical and extensible direction for unifying search and recommendation through generativemodeling.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现代Feed推荐系统与搜索系统虽然在用户行为上紧密关联（例如用户从推荐中发现主题，进而搜索查询，再返回推荐），但通常采用独立架构分别建模。推荐系统依赖隐式反馈（点击、停留等），搜索系统依赖显式查询。这种分离导致用户理解碎片化，无法充分利用Feed交互改进查询生成，也无法利用生成查询增强推荐候选检索。
- **含义**：需要一种统一的生成式框架，将Feed内容增强（即预测用户下一步可能消费的内容）与意图查询生成（即预测用户可能显式表达的搜索查询）联合建模，形成闭环，实现双向知识迁移。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：OneFeed通过共享行为编码器对异构用户行为序列进行编码，然后使用两个生成头分别生成内容语义ID（用于推荐检索）和自然语言查询（用于搜索候选扩展）。通过SID-Query对比对齐目标弥合推荐内容与查询的语义鸿沟，并设计闭环自增强范式利用用户隐式反馈持续改进。

- **关键技术细节**：
  - **统一行为编码器**：将每个行为项表示为多种嵌入之和：动作类型、内容语义ID、可选查询、时间差、交互强度。序列送入Transformer编码器，支持自回归或前缀语言模型。
  - **内容语义ID构建**：首先对物品的多模态/文本表征进行层次量化/聚类，然后利用行为信息（共点击、共搜索等）进行校准，使行为相似的物品共享语义前缀。
  - **Feed SID生成器**：自回归生成目标物品的层次语义ID令牌序列，通过语义ID索引映射到候选物品。
  - **意图查询生成器**：基于共享用户表征生成一组自然语言查询，训练数据来自真实搜索日志或弱监督构造的伪查询。
  - **SID-Query对齐**：采用对比学习损失，将正例（相同意图的SID与查询）的表征拉近，负例推开，使得推荐语义和搜索语义对齐。
  - **候选增强一致性损失**：确保生成查询不仅文本相似，还能检索到有用候选；通过对比检索到的正负候选的得分差来优化。
  - **整体训练目标**：L = α L_feed + β L_query + γ L_align + δ L_cons，其中L_feed为主任务，其余提供跨任务监督。
  - **闭环自增强**：生成SID和查询后，合并候选并排序，根据用户隐式反馈（点击、停留等）转化为训练信号，模拟离线训练迭代。

## 3. 实验设计：数据集、场景、基准方法

- **数据集**：三个公开推荐数据集：
  - **KuaiRec**：密集用户-视频交互日志，用于序列评估。
  - **Amazon Reviews**：包含商品标题、类别、评论，用于弱监督查询构建。
  - **MovieLens-1M**：经典序列推荐基准，适合冷启动分析。
- **弱监督查询构建**：由于公开数据集没有真实搜索查询，从物品元数据（标题、类别、标签、高频关键词）中构造伪查询，并遵循时间顺序防泄漏。
- **基准方法**：
  - 推荐基线：GRU4Rec、SASRec、BERT4Rec、P5风格生成推荐、OneRec风格语义ID生成、多任务双塔模型。
  - 查询生成基线：关键词提取、T5-base、BART-base、GPT2微调、独立查询生成模型。
  - 融合基线：仅Feed检索、仅查询检索、双塔融合、晚融合搜索-推荐检索。
- **评估指标**：
  - 推荐质量：Recall@K, NDCG@K, HR@K, MRR@K。
  - 查询生成质量：BLEU, ROUGE-L, BERTScore, Distinct-n, Retrievability（至少检索到一个有效候选的比例）。
  - 候选增强：候选覆盖率、长尾召回、搜索补充比率、离线回放NDCG。
