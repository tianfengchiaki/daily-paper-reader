## 摘要
大语言模型（LLM）正越来越多地被用作生成式推荐（GR）的骨干，有望获取预训练的世界知识。然而，如何可靠地调用这些知识进行GR仍未被充分理解。一个关键障碍是，基于LLM的GR通常使用语义ID（SID）来表示物品，这扰乱了LLM的自然语言推理接口，因为这些token在预训练期间对LLM不可见。现有方法通过昂贵的多阶段流水线来解决这一问题，这些流水线将SID接地并引出显式理由，但在每个阶段何时以及为何必要时提供的见解有限。在这项工作中，我们系统地分解了基于LLM的GR的显式推理训练流水线，揭示了三个关键限制：弱化的世界知识言语化、SID与自然语言token嵌入空间之间的不对齐，以及对理由质量的敏感性，所有这些都损害了显式推理性能。为了规避这些问题，我们提出了PauseRec，一种专为GR设计的轻量级隐式推理范式。PauseRec非常实用，避免了昂贵的推理轨迹获取和推理对齐训练，带来了诸多好处：（1）其性能比标准的显式CoT方法高出最多6.22%，（2）训练成本降低最多65%的GPU小时，（3）推理速度提升最多71.3%。这些结果使PauseRec成为显式理由生成的一种轻量级替代方案，实现了更有效且高效的基于LLM的GR。

## Abstract
Large Language Models (LLMs) are increasingly adopted as backbones for Generative Recommendation (GR), promising access to pretrained world knowledge. Yet reliably invoking this knowledge for GR remains poorly understood. A key obstacle is that LLM-based GR typically represents items with Semantic IDs (SIDs), disrupting LLMs' natural-language reasoning interface because these tokens are unseen by the LLM during pretraining. Existing approaches address this with expensive multi-stage pipelines that ground SIDs and elicit explicit rationales, but offer limited insight into when and why each stage is necessary. In this work, we systematically decompose explicit reasoning training pipelines for LLM-based GR, revealing three key limitations: weakened world-knowledge verbalization, misalignment between SID and natural-language token embedding spaces, and sensitivity to rationale quality, all of which hurt explicit reasoning performance. To circumvent these issues, we propose PauseRec, a lightweight implicit reasoning paradigm tailored for GR. PauseRec is exceptionally practical, avoiding costly reasoning trace acquisition and reasoning alignment training, leading to a multitude of benefits: (1) it outperforms standard explicit CoT methods by up to 6.22%, (2) it reduces training cost by up to 65% GPU hours, and (3) it speeds up inference by up to 71.3%. These results position PauseRec as a lightweight alternative to explicit rationale generation, enabling more effective and efficient LLM-based GR.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**: 大语言模型（LLM）用于生成式推荐（GR）时，通常使用语义ID（SID）表示物品。SID是LLM预训练时未见的特殊token，破坏了LLM的自然语言推理接口，导致难以有效调用其预训练的世界知识。
- **现有方法局限**: 现有显式推理（Chain-of-Thought, CoT）方法通过昂贵多阶段流水线（持续预训练CPT、监督微调SFT、CoT SFT、强化学习RL）来接地SID并生成显式理由，但存在三个关键问题：
  1. 世界知识言语化困难（知识仍存在于logits但无法可靠生成文本）；
  2. 文本token与SID token嵌入空间几何分离，限制显式理由对最终SID预测的影响；
  3. 推荐性能对理由质量高度敏感，即使是微小扰动也会严重下降。
- **研究目标**: 提出一种轻量级隐式推理范式，避免显式理由生成和对齐训练，同时保持或提升推荐性能。

## 2. 方法论：PauseRec
- **核心思想**: 使用可训练的`<pause>` token插入在SID生成之前，作为隐式推理步骤，不生成自然语言理由。`<pause>` token在隐空间中进行计算，直接塑造SID预测。
- **关键技术细节**:
  1. **`<pause>` token初始化**: 初始化为所有token嵌入的均值（中心点，方差极小），作为文本与SID间的中性起点。
  2. **两阶段训练**:
     - **阶段1: `<pause>` token预训练**：基于CPT语料库（SID与文本描述对），将`<pause>` token随机插入序列的10%位置，仅训练该token嵌入，其余参数冻结。目的是桥接文本和SID表示空间。
     - **阶段2: 隐式推理SFT**：在SFT checkpoint基础上，在用户历史与目标SID之间插入k个`<pause>` token。训练时仅优化目标SID位置的损失，不监督`<pause>` token生成内容。损失函数为：
       ```
       L_implicit = - Σ log p(SID | 用户历史 + k个<pause>)
       ```
       其中损失在`<pause>`位置被mask。
  3. **推理**: 输入时在`<think>`和`</think>`标记之间插入k个`<pause>` token，然后自回归解码SID，不生成任何自然语言理由。
- **优势**: 消除了对显式理由的依赖，避免了知识言语化问题、嵌入空间不对齐和理由敏感性问题。

## 6. 主要结论与发现
- **显式CoT在SID-based GR中效果有限**：CPT只能恢复粗粒度类别，无法提供精确物品级语义；CoT SFT在所有变体下均未超越简单Next-item SFT；失败原因包括知识言语化困难、嵌入空间不对齐、理由敏感。
- **PauseRec隐式推理有效**：
  - 性能优于Next-item SFT和所有显式CoT变体，最高提升6.22%（Toys Hit@5）。
  - 在10/12指标上超越OneRec-Think（含昂贵RL）。
  - 训练成本降低65%，推理速度提升71.3%。
- **`<pause>` token的作用**: 位于文本和SID嵌入空间边界，提供桥接；注意力分析显示多阶段过程（初期关注上下文，后期聚焦历史SID）。
