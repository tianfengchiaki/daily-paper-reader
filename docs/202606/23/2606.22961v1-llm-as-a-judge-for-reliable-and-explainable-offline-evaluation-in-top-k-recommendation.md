## 摘要
推荐评估在指导推荐系统的优化和部署中起着关键作用。现有的大多数尝试依赖于使用基于留出用户行为计算的Top-K指标进行离线评估。然而，我们发现了两个基本局限性，削弱了它们提供可靠且可解释评估的能力。在可靠性方面，离线评估将观察到的用户反馈视为真实偏好的代理，并在代理与推荐之间强制执行严格的ID匹配。在实践中，反馈收集本质上受到不完整和有偏的物品曝光的塑造，导致扭曲且不可靠的评估。在可解释性方面，Top-K指标仅建立数值分数，而不提供有意义的见解来支持这些分数，从而强化了离线评估的黑箱性质。在本文中，我们提出了一种可靠且可解释的基于LLM评判器的离线推荐评估框架。为了提高可靠性，我们从用户文本行为中引入一个语义代理来表示他们的真实偏好。该代理允许在语义空间中更灵活地匹配偏好和推荐，而不是依赖于留出反馈。为了确保可解释性，LLM评判器采用先推理后评分的过程来生成相关性判断以及显式的理由。最后，我们将各个分数聚合为全局Top-K指标以量化整体推荐质量，并为每个偏好命中或未命中提供理由。大量实验表明，LLM评判器在评估中实现了可靠的可靠性、可解释性和鲁棒性。

## Abstract
Recommendation evaluation plays a crucial role in guiding the refinement and deployment of recommender systems. Most existing trials rely on offline evaluation using Top-K metrics computed over holdout user behaviors. However, we identify two fundamental limitations that undermine their ability to deliver reliable and explainable evaluations. Regarding reliability, offline evaluation treats observed user feedback as a proxy of true preferences and enforces rigid ID matching between the proxy and recommendation. In practice, feedback collections are inherently shaped by incomplete and biased item exposure, leading to distorted and unreliable assessments. Regarding explainability, Top-K metrics only establish numerical scores without offering meaningful insights to support them, thereby reinforcing the black-box nature of offline evaluation.   In this paper, we propose a reliable and explainable LLM-as-a-Judge framework for offline recommendation evaluation. To enhance reliability, we introduce a semantic proxy from user textual behaviors to represent their true preferences. This proxy allows for more flexible matching between preferences and recommendations in the semantic space, rather than depending on the holdout feedback. To ensure explainability, the LLM Judge adopts a reasoning-then-scoring process to generate relevance judgments along with explicit rationale. Finally, we aggregate the individual scores into global Top-K metrics to quantify overall recommendation quality, and provide justification for each preference hit or miss. Extensive experiments demonstrate that the LLM Judge achieves solid reliability, explainability, and robustness in evaluation.

# 论文总结：LLM-as-a-Judge for Reliable and Explainable Offline Evaluation in Top-K Recommendation

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：推荐系统评估中，传统离线评估采用 Top-K 指标（如 Recall@K、NDCG@K）在留出用户行为数据上计算。但由于用户反馈存在缺失非随机（Missing-Not-At-Random, MNAR）偏差，即用户只暴露于部分物品、只反馈了部分偏好，导致离线评估结果失真、不可靠。
- **核心问题**：现有离线评估存在两个根本局限：  
  1. **可靠性不足**：将观察到的用户反馈当作真实偏好代理，并强制执行严格的 ID 匹配，忽略了未观测的兴趣。  
  2. **可解释性缺失**：仅输出数值分数，缺乏支持决策的理性解释，使评估成为黑箱。
- **研究含义**：需要一种更可靠且可解释的离线评估方法，能够更好地逼近“匹配用户真实偏好空间”的金标准。

## 2. 方法论：核心思想、关键技术细节、流程

- **核心思想**：利用大语言模型（LLM）的语义理解与推理能力，构建**语义代理**（Semantic Proxy）表示用户真实偏好，替代传统留出反馈代理；再通过**语义匹配**（Semantic Matching）灵活评估推荐列表，并输出显式理由。
- **关键技术细节**：
  1. **语义代理构建**：从用户历史交互文本（标题、属性、描述等）中，由 LLM 推理出用户高层兴趣（如“科幻”、“技术”、“未来AI”），形成语义表征。
  2. **推理-评分两阶段判断**（封装在单次 LLM 查询中）：  
     - **推理步骤**：LLM 先总结用户偏好（语义代理），然后对每个候选推荐项进行链式推理，给出匹配或不匹配的证据。  
     - **评分步骤**：基于推理输出二进制相关性分数（1 = 命中，0 = 拒绝），并附上一句话理由。
  3. **拒绝优先策略**（Reject-by-Default）：默认拒绝（0），除非有明确证据完美匹配，以减少 LLM 过度乐观的倾向。
  4. **聚合全局指标**：将每个用户的点状判断聚合为类似 Recall@K 和 NDCG@K 的全局指标（Recall^Judge@K 按 K 归一化）。
- **公式与算法流程**（文字说明）：
  - 给定用户历史文本和推荐列表 π_K(u)，LLM 输出二元判断 y_{u,i_r} ∈ {0,1}。
  - Recall^Judge@K = (1/|U|) Σ_u (1/K) Σ_{r=1}^{K} y_{u,i_r}。
  - NDCG^Judge@K 使用标准 DCG 公式，以 y_{u,i_r} 为相关性信号计算。
- **提示设计**：包含固定基本原则（推理-评分、拒绝优先）、可定制输入字段（任务定义、匹配标准、历史、候选）和固定输出格式（JSON 含 reason 和 score）。

## 3. 实验设计

- **数据集**：
  - **Kuairec**：视频推荐数据集，1250 万交互，7.1k 用户，10.7k 物品。提供全观测测试子集（1.4k 用户，3.3k 物品）作为无偏 ground truth。
  - **Coat**：服装购物平台，290 用户，300 物品，提供随机暴露的无偏测试集。  
- **基准方法**：  
  - **正常测试（Normal Testing）**：传统离线评估，用留出验证集作为代理，视为性能下限。  
  - **无偏测试（Unbiased Testing）**：用全观测测试集进行评估，视为性能上限和 ground truth。  
  - **LLM Judge**：使用相同的推荐模型产生的推荐列表，由 LLM 评估。
- **对比方法**：对比了 9 种不同的协同过滤推荐模型（MF, NeuMF, NGCF, LR-GCCF, LightGCN, SimGCL, MGCCF, GTN, CAGED）的性能排序，以验证 LLM Judge 能否恢复无偏排序。
- **评估指标**：
  - **可靠性**：Pearson 相关系数、Spearman 秩相关系数、Kendall τ、MAE。
  - **可解释性**：人工评估（3 位标注员）对理由的连贯性、忠实性、说服力进行评分（Fleiss’ κ > 0.75）。
  - **鲁棒性**：不同 LLM 规模（Qwen3-4B/8B/14B/30B、DeepSeek-V3.2）以及提示和输入长度的消融。

1. **可靠性**：LLM Judge 在几乎所有 Top-K 指标上的排序一致性和分数一致性均显著优于传统正常测试，且相关性达到统计显著（p < 0.05）。在 Coat 的 NDCG 评估中，甚至将负相关逆转为正相关。

4. **总结**：LLM-as-a-Judge 框架有效解决了离线评估的偏差和黑箱问题，提供了可靠且可解释的评估结果，且具有跨模型、跨配置的鲁棒性。

## 7. 优点

- **方法创新**：首次在推荐评估中系统引入语义代理和语义匹配，替代传统的 ID 匹配，从根本上缓解了 MNAR 偏差。
- **可解释性内生**：推理-评分机制使得每个判断都附带理由，支持人工审查和错误分析，弥补了离线评估的黑箱缺陷。
- **模块化提示设计**：可灵活适配不同推荐任务（只需调整输入字段和匹配标准），具有良好的通用性。
- **实验充分且严谨**：使用无偏 ground truth 作为黄金标准，对比多种推荐模型，评估指标多样（排序、分数、人工理由评分、鲁棒性消融），结果说服力强。
- **开源代码**：提供了公开代码，促进复现和后续研究。

## 8. 不足与局限

- **适用范围限制**：仅适用于 **Top-K 协同过滤推荐**场景，且要求物品附带文本描述（不能仅有 ID）。对纯 ID 型数据集（如 Yahoo!R3）不适用。
- **LLM 成本与延迟**：虽然实验表明在 RTX A6000 上单次调用延迟在 100ms 以内，但在大规模评估（如百万用户、百个候选）时累积成本仍较高，可能限制实时或全量部署。
- **依赖 LLM 能力**：评估质量受 LLM 世界观、偏见和幻觉影响。虽然采用了拒绝优先策略，但仍需谨慎分析误判（尤其是复杂隐式偏好）。
- **可解释性评估主观性**：人工评分虽然一致性高，但仅评估了 200 条理由，样本量有限。且“说服力”等指标存在主观偏差。
- **冷启动问题**：当历史交互极少（10% 历史，对应 Coat 的约 1-2 个物品）时，LLM 评估完全失效，这与传统离线评估在冷启动场景下的局限性类似，未提供额外解决方案。
- **未探索更复杂的评价维度**：如用户多样性、新颖性、公平性等；仅聚焦于相关性评估。
- **统计显著性标注不完整**：部分结果（如 Kuairec Recall@50 的 Spearman）未标注星号（p < 0.05），但数值较高；未讨论这些例外的原因。
