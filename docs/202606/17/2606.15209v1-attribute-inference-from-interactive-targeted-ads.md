## 摘要
定向广告系统可以将广告主选择的受众与展示可见用户行为的广告单元配对。当交互行为仍与引发它的广告活动相关联时，广告主可能获得与用户相关的观察结果，而不仅仅是聚合报告。我们将该渠道建模为用于属性推断的带噪预言机。该模型将定向谓词、曝光、交互和披露分开。这些边界捕捉了资格与投放之间的差距，以及交互与广告主可见性之间的差距。我们使用根据公开数据校准的合成人群构建了一个可复现的基准测试，每个合成人群具有已知的敏感标签。生成的广告活动语义层提供主题变体和响应先验。模拟器生成真实标签、事件轨迹、已披露的观察结果和指标。评估比较了在常见广告活动和披露定义下的贝叶斯攻击、监督攻击、正样本与未标签攻击以及自适应攻击。最终评估使用了四个主题变体、七个模拟种子和两个交互设置。具有身份暴露的重复广告活动产生了可测量但有限的推断信号。在160个广告活动下，主设置中贝叶斯和监督攻击的AUC达到约0.64，较高交互设置中约达到0.65。披露政策是最强的控制手段。聚合报告移除了与用户绑定的评估预言机输入。类型过滤和随机化披露减少了释放的信号。结果是针对交互式定向广告隐私的一个模型、工件和防御评估方法。代码可在https://github.com/P-HOW/Interactive-Ad-Oracle获取。

## Abstract
Targeted advertising systems can pair audiences selected by advertisers with ad units that expose visible user actions. When an interaction remains linked to the campaign that elicited it, the advertiser may receive an observation tied to a user rather than only an aggregate report. We model that channel as a noisy oracle for attribute inference. The model separates targeting predicates, exposure, interaction, and disclosure. These boundaries capture the gap between eligibility and delivery, and the gap between interaction and advertiser visibility.   We build a reproducible benchmark using synthetic populations calibrated with public data, each with known sensitive labels. A generated campaign semantics layer provides topic variants and response priors. The simulator generates the ground truth, event traces, disclosed observations, and metrics. The evaluation compares Bayesian, supervised, positive and unlabeled, and adaptive attacks under common campaign and disclosure definitions.   The final evaluation uses four topic variants, seven simulator seeds, and two interaction settings. Repeated campaigns with identity exposure produce measurable but bounded inference signal. At $160$ campaigns, Bayesian and supervised attacks reach about $0.64$ AUC in the main setting and about $0.65$ AUC in the higher interaction setting. Disclosure policy is the strongest control. Aggregate reporting removes the evaluated oracle input tied to users. Type filtering and randomized disclosure reduce the released signal. The result is a model, artifact, and defense evaluation method for privacy in interactive targeted advertising. The code is available at https://github.com/P-HOW/Interactive-Ad-Oracle.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：在交互式定向广告系统中，广告主可以选择特定受众并投放支持用户可见交互（如点赞、评论）的广告。当用户的交互行为暴露其身份并与广告活动关联时，广告主能否通过这些暴露的交互记录推断用户的敏感属性（如健康状况、政治倾向等）？这种推断的风险有多大？如何通过平台侧的披露控制来防御？
- **背景**：已有工作表明，定向广告的受众构建、投放优化和透明度接口可能泄露信息（Korolova 2011；Andreou 2018等）。但交互式广告增加了“身份暴露的交互”这一新信号，且该信号与广告主选择的谓词（targeting predicate）绑定，构成一个带噪的查询预言机。此前缺乏对这一通道的系统性建模和基准评估。
- **核心含义**：本文首次将交互式定向广告中身份暴露的交互行为形式化为一个带噪的属性推断预言机，并提供了可复现的基准测试、攻击方法对比和防御评估框架，为隐私保护设计提供了定量依据。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将广告系统抽象为四个阶段：**定向谓词选择**（广告主选择受众条件） → **投放与曝光**（平台决定实际投送哪些用户） → **用户交互**（用户对广告做出反应） → **披露**（平台决定是否将交互记录（含身份）暴露给广告主）。每个阶段都有噪声，使得曝光 ≠ 投放，交互 ≠ 广告主可见。广告主通过反复投放广告，收集目标用户的交互历史 H(T)_u，从而进行属性推断。
- **关键技术细节**：
  - **用户与广告活动模型**：用户 u 有特征 X_u 和二进制敏感属性 S_u。广告活动 c = (g_c, a_c, b_c)，其中 g_c 为谓词（布尔表达式），a_c 为广告创意/主题，b_c 为预算。符合平台约束（最低受众规模、预算上限、允许的谓词集合）的活动属于合法空间 C_legal。
  - **曝光与交互**：曝光 E_u,c ~ Bernoulli(p_E)，且满足资格单调性（符合谓词的用户曝光概率更高）。交互 R_u,c 仅在曝光后发生，概率 p_R 依赖于用户特征、敏感属性、广告主题等参数。
  - **披露策略 D**：定义广告主能观察到的用户绑定的记录 Y_u,c。包括：
    - 身份暴露（identity exposure）：交互发生时直接暴露用户身份。
    - 类型过滤（type filtering）：仅暴露某些交互类型。
    - 随机化身份披露（randomized identity disclosure）：以概率 ρ 释放身份。
    - 阈值披露（k-threshold）：仅当交互总数 ≥ k 时释放身份。
    - 聚合报告（aggregate reporting）：只给出总交互数，无用户级记录。
  - **攻击模型**：攻击者（广告主）的目标是从用户 u 的历史 H(T)_u 推断 S_u。
    - **贝叶斯攻击**：假设条件独立，计算后验对数几率。
    - **监督影子攻击**：用合成用户训练分类器（逻辑回归、随机森林、梯度提升树），从历史特征映射到 S_u。
    - **正无标签攻击**：将身份暴露的交互视为正样本，未暴露的记录视为负或未标记。
    - **自适应攻击**：根据前序观察结果选择下一个合法广告活动，最大化预期信息增益（按成本归一化）。
  - **停止规则**：设定置信阈值 τ，当后验概率 max(s(u), 1-s(u)) ≥ τ 时停止，记录所需活动次数 T_τ(u) 和成本 C_τ(u)。

## 6. 主要结论与发现

1. **RQ1（是否存在推断通道）**：重复投放身份暴露的交互式广告会产生可测量但有限的推断信号。在 160 个广告活动下，贝叶斯和监督攻击 AUC 约 0.64（主设置）/ 0.65（高交互设置），显著高于随机猜测（0.5），但远非完美。
2. **RQ2（风险如何随参数变化）**：推断信号随广告活动数量和交互密度单调增长；较窄的谓词（长度 1）能保持信号，但更窄的谓词（长度 3）因减少曝光机会而几乎回到先验水平；披露政策是主导控制因素。
3. **RQ3（自适应攻击是否更高效）**：自适应策略可以减少达到置信阈值所需的广告活动数量，但在主设置中高置信决策仍只占少部分（约 17.2% 的用户达到 0.70 置信度）。成本归一化的自适应选择比贪心选择更优。
4. **RQ4（哪些防御有效）**：
   - **聚合报告**完全移除用户级历史输入，AUC 回到 0.5。
   - **类型过滤**和**随机化身份披露**可降低但无法完全消除信号（AUC 下降约 0.05-0.06）。
   - **阈值披露**在模拟的交互分布下几乎未发挥作用（因阈值未绑定）。
   - **最小受众约束**本身不足以防止推断，但影响谓词可用性。
- **核心启示**：隐私风险主要源自披露策略的设计，而非仅依赖定向政策文本。平台应在披露层实施更严格的保护（如默认聚合报告），并评估实际绑定阈值。

## 8. 不足与局限

1. **合成数据局限**：所有结论基于合成用户，未在真实平台（如 Facebook、Instagram）上验证界面行为是否符合模型假设。虽然作者建议通过受控账户进行验证，但文章中未进行此类实验。
2. **单一敏感属性**：实验仅针对 health_interest 标签，未验证其他敏感属性（如政治倾向、财务压力）下的可迁移性。
3. **简化假设**：
   - 假设条件独立（贝叶斯攻击）或影子数据分布与目标一致（监督攻击），现实中广告主可能无法获得完美校准数据。
   - 假设广告主知道每个活动的谓词（合法合理），但真实中平台可能对谓词进行模糊化或隐藏。
   - 忽略跨平台追踪、用户动态变化、广告竞价等复杂因素。
4. **自适应攻击评估有限**：仅评估单目标、单轮自适应（基于信息增益），未考虑多目标并行攻击或更复杂的强化学习策略。
5. **未考虑隐私预算**：虽然使用了随机化响应和阈值，但未引入差分隐私框架进行严格隐私保护评估，可能低估了噪声机制的泄漏。
6. **可扩展性**：合成用户规模仅 8000，真实平台用户量级达数亿，节点性行为（如交互率）的模拟可能无法完全反映大规模系统的统计特性。
7. **缺乏对攻击成本的实际度量**：成本仅用归一化预算表示，未考虑真实广告竞价的货币成本和投放延迟。
