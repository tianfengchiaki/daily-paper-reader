## 摘要
短视频平台现在在视频播放器下方展示可点击的搜索入口，使用户能够轻松表达由内容引发的搜索意图。然而，短视频平台上传统的查询推荐系统受到延迟约束和目标不一致的影响，而近期的生成式方法则面临内容侧元数据噪声和偏好漂移的问题。为了解决这些问题，我们提出了OneBar，一种用于电商视频流实时查询推荐的端到端生成框架。OneBar具有三个关键创新：（1）协作多模态意图基础模块，融合了多模态视频理解和行为衍生的协作锚点；（2）统一端到端架构，配备提示压缩机制以实现高效的在线服务；（3）渐进式偏好学习策略，用于高效的偏好内化，将层次化行为偏好内化到生成策略中，无需单独训练奖励模型。与在线基线相比，OneBar将查询曝光率提高了16.91%，查询点击率提高了18.68%，同时保持查询点击率略有提升（0.19%）。额外的搜索流量进一步带来了20.36%的引导订单增加和21.67%的GMV增长。

## Abstract
Short-video platforms now expose clickable search entries beneath the video player, enabling users to easily express content-induced search intent. However, conventional query recommendation systems on short-video platforms suffer from latency constraints and objective misalignment, while recent generative approaches struggle with noisy content-side metadata and preference drift. To address these issues, we propose OneBar, an end-to-end generative framework for real-time query recommendation for E-Commerce video feeds. OneBar features three key innovations: (1) a collaborative-multimodal intent grounding module that fuses multimodal video understanding and behavior-derived collaborative anchors; (2) a Unified End-to-End architecture equipped with a prompt-compression mechanism for efficient online serving; and (3) a progressive preference learning strategy for efficient preference-internalization, which internalizes hierarchical behavior preferences into the generative policy, eliminating the need for a separately trained reward model. Compared with online base, OneBar increases Query Exposure by 16.91\% and Query Click by 18.68\%, while maintaining a slight Query CTR gain of 0.19\%. The additional search traffic further contributes to 20.36\% more guided orders and 21.67\% higher GMV.

**整体含义**：

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
OneBar将查询推荐建模为端到端的生成任务，输入为当前视频和用户上下文，直接输出有序查询列表。它通过三个关键模块实现：
- **协作多模态意图接地**：融合多模态视频理解与行为衍生的协作锚点，构建结构化证据模式 \(E(x,u) = \langle T_x, M_x, A_x, H_{x,u} \rangle\)。
- **低延迟统一端到端生成**：使用BART编码器-解码器，将多种证据压缩为[SEP]分隔的紧凑提示，支持实时在线生成。
- **渐进偏好内化**：通过三个阶段（SFT、列表式DPO、PIOPD）逐步将用户行为偏好内化到生成策略中，无需独立奖励模型。

### 关键技术细节

**① 协作多模态意图接地**
- 文本证据 \(T_x\)：清理标题、去除@提及、标签等噪声。
- 多模态证据 \(M_x\)：利用多模态基础模型（如视频摘要）提取视觉对象、OCR、ASR、场景等。
- 协作锚点 \(A_x\)：
  - **ANN检索锚点**：训练Qwen3-Embedding模型，通过行为监督（搜索-点击、观看后搜索、查询改写）对齐查询和视频，检索相似视频的关联查询，相似度阈值>0.88。
  - **RAG历史**：该视频历史关联查询的聚合。
- 个性化证据 \(H_u\)：仅保留与当前视频相似度高的用户历史查询。

**② 低延迟统一生成**
- 证据序列化为：\(s_x = [T_x; [SEP]; M_x; [SEP]; A_x; [SEP]; H_u]\)。
- 使用BART作为生成器，输出分布 \(p_\theta(y|s_x)\)。
- 引入特殊标记[REJECT]使模型能够在无法生成安全、相关查询时弃权。
- 推理时使用束搜索（宽度K=8），随后进行轻量级去重、安全检查和业务规则过滤。

**③ 渐进偏好内化（三阶段训练）**
- **阶段一：内容接地SFT**：从在线点击日志中构建触发-查询对（\(D_{pos}\)），以及安全拒绝样本（\(D_{rej}\)），训练标准的下一个令牌预测损失 \(L_{SFT}\)。
- **阶段二：列表式用户反馈对齐（Behavior Feedback Preference Alignment）**：
  - 将候选查询按6级行为偏好排序（从“当前用户点击并深度互动”到“检索但未曝光”）。
  - 通过单调CTR过滤去除噪声，每级保留一个代表，形成有序列表 \(Y_x = [y_1 \succ y_2 \succ \cdots \succ y_n], n \leq 6\)。
  - 损失函数：列表式Softmax DPO，对于每个点击锚点 \(y_j\)，对比其后所有较低级别候选，损失为：
\[
L_{\text{Stage-II}}(x) = \sum_{j \in C_x} \left[ \log\left(1 + \sum_{i=j+1}^n \exp\left(\frac{\beta}{T}(r_i - r_j)\right)\right) - \lambda_{\text{SFT}} \ell_\theta(y_j|x) \right]
\]
其中 \(r_i = \ell_\theta(y_i|x) - \ell_{\text{ref}}(y_i|x)\)，\(\beta=0.1, T=1.0, \lambda_{\text{SFT}}=1.0\)。

- **阶段三：偏好内化在线策略蒸馏（PIOPD）**：
  - 教师模型输入包含随机插入点击查询的提示（Randomized Context Augmentation）；学生模型输入为标准提示。
  - 学生模型自回归采样轨迹，教师和学生计算在同一前缀上的logits，最小化双向KL散度（FKL+RKL）：
\[
L_{\text{Distill}} = E_{y \sim \pi_\theta(\cdot|x^{(S)})} \sum_t \tau^2 \left[ \lambda_{\text{FKL}} D_{KL}(p_t^{T,\tau} \| p_t^S) + \lambda_{\text{RKL}} D_{KL}(p_t^S \| p_t^{T,\tau}) \right]
\]
- 附加正则项：SFT损失、熵正则（鼓励多样性）、R-Drop（输出一致性）、FGM（输入平滑）。
- 最终损失：\(L_{\text{PIOPD}} = L_{\text{SFT}} + L_{\text{Distill}} + \lambda_E L_{\text{Ent}} + \lambda_{\text{RD}} L_{\text{RDrop}} + \lambda_{\text{FGM}} L_{\text{FGM}}\)。
- 训练后丢弃教师模型，仅保留学生模型用于在线推理。

## 6. 主要结论与发现

1. **整体有效性**：OneBar在线相比MCA提升显著：Query曝光+16.91%，Query点击+18.68%，CTR保持+0.19%，引导订单+20.36%，GMV+21.67%。
2. **人工评估**：OneBar将整体查询质量坏案例率降低9.00个百分点（相关性-3.66pp，文字质量-1.00pp，风控-4.33pp）。
3. **多模态证据的重要性**：每个额外证据源（多模态、协作锚点、个性化）均持续提升离线HR@8。
4. **紧凑提示格式胜过冗长指令**：[SEP]分隔格式（HR@8 0.3564）远优于详细提示格式（0.1864）。
5. **渐进训练的优势**：完整的SFT → Stage II → PIOPD 三阶段训练得到最佳结果（HR@8 0.3690），跳过Stage II或跳过PIOPD均下降。
6. **PIOPD设计选择**：双向KL（FKL+RKL）优于单一KL或JSD；全词汇蒸馏优于top-k截断；随机插入教师提示优于固定插入；冻结教师优于EMA更新；结合熵正则、R-Drop、FGM进一步提升。
7. **新鲜视频获益更大**：OneBar在发布30天内的新视频上CTR提升显著，归因于多模态意图接地提供了内容理解。
8. **对不同用户群体均有效**：从低活跃到高活跃用户均有正向收益。

## 7. 优点（方法或实验设计亮点）

- **端到端生成取代多阶段级联**：显著降低延迟并统一优化目标，且支持实时上下文利用。

- **完整的在线验证**：在快手真实亿级流量环境中进行A/B测试，并辅以人工评估，验证了业务指标和用户体验的双重提升。

- **离线评估的公平性**：进行了数据去污染，防止历史信息泄露导致指标虚高；使用多种互补指标（精确匹配、编辑距离容忍、BLEU、语义相关性）衡量生成质量。
