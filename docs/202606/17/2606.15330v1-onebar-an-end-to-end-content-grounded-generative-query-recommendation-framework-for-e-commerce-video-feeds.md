## 摘要
短视频平台现在在视频播放器下方显示可点击的搜索条目，使用户能够轻松表达由内容引发的搜索意图。然而，短视频平台上传统的查询推荐系统受限于延迟约束和目标不一致，而最近的生成式方法则面临内容侧元数据噪声和偏好漂移的问题。为了解决这些问题，我们提出了OneBar，一种用于电商视频流实时查询推荐的端到端生成式框架。OneBar具有三项关键创新：（1）协同多模态意图接地模块，融合了多模态视频理解和行为衍生的协同锚点；（2）统一端到端架构，配备提示压缩机制以实现高效在线服务；（3）渐进式偏好学习策略，用于高效偏好内化，将层次化行为偏好内化到生成策略中，无需单独训练的奖励模型。与在线基准相比，OneBar的查询曝光量提升了16.91%，查询点击量提升了18.68%，同时保持了微小的0.19%的查询点击率提升。额外的搜索流量进一步贡献了20.36%的引导订单增长和21.67%的GMV增长。

## Abstract
Short-video platforms now expose clickable search entries beneath the video player, enabling users to easily express content-induced search intent. However, conventional query recommendation systems on short-video platforms suffer from latency constraints and objective misalignment, while recent generative approaches struggle with noisy content-side metadata and preference drift. To address these issues, we propose OneBar, an end-to-end generative framework for real-time query recommendation for E-Commerce video feeds. OneBar features three key innovations: (1) a collaborative-multimodal intent grounding module that fuses multimodal video understanding and behavior-derived collaborative anchors; (2) a Unified End-to-End architecture equipped with a prompt-compression mechanism for efficient online serving; and (3) a progressive preference learning strategy for efficient preference-internalization, which internalizes hierarchical behavior preferences into the generative policy, eliminating the need for a separately trained reward model. Compared with online base, OneBar increases Query Exposure by 16.91\% and Query Click by 18.68\%, while maintaining a slight Query CTR gain of 0.19\%. The additional search traffic further contributes to 20.36\% more guided orders and 21.67\% higher GMV.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：短视频电商平台在视频播放器下方提供“底部栏”查询推荐，以引导用户从内容浏览转向商品搜索。传统查询推荐方法（基于多级检索级联 MCA）受限于严格的延迟预算（约 20-30 ms），只能依赖离线预计算缓存，无法利用实时视频上下文，导致查询新鲜度差、长尾覆盖不足；同时多级级联优化目标碎片化，难以联合优化相关性、点击率和下游转化。现有生成式方法（如 GREAT、CLICKABLE）虽尝试端到端生成，但受限于内容侧元数据噪声（标题、标签等）和偏好漂移，且依赖单独训练的奖励模型会引入偏差与奖励破解风险。
- **整体含义**：提出了 **OneBar**，首个在工业短视频平台大规模部署的、用于实时底部栏查询推荐的端到端生成式框架，通过协同多模态意图接地、紧凑提示压缩和渐进偏好内化，在不增加延迟的前提下显著提升查询质量、搜索流量和电商转化。

## 2. 论文提出的方法论

### 核心思想
将底部栏查询推荐建模为条件生成任务：给定当前播放视频证据和用户上下文，直接生成有序查询列表。通过“渐进偏好内化”三步训练，将层次化用户行为偏好注入生成策略，无需额外奖励模型。

### 关键技术细节

- **协同多模态意图接地**：将每个视频印象抽象为结构化证据模式 \(E(x,u) = \langle T_x, M_x, A_x, H_{x,u}\rangle\)：
  - \(T_x\)：清洗后的视频标题（去除@、标签、促销词）
  - \(M_x\)：多模态摘要（通过多模态基础模型对采样帧和ASR生成，每日离线刷新）
  - \(A_x\)：协同行为锚点（包含ANN检索的行为对齐查询嵌入检索到的相似视频的查询，以及RAG历史查看记录）
  - \(H_{u}\)：用户历史过滤（仅保留与当前视频行为相似度超过阈值的查询）
- **低延迟统一端到端生成**：用 `[SEP]` 分隔四个证据字段形成紧凑输入 \(s_x\)，送入 BART 编码器-解码器。支持 `[REJECT]` 特殊 token 实现拒绝式生成（当无安全、相关查询时）。在线推理用束搜索（宽度 8），轻量去重和安全检查后曝光。
- **渐进偏好内化**（三步训练）：
  - **Stage I: 内容接地 SFT**：从在线点击日志构建（视频证据，点击查询）对，同时加入安全拒绝样本（输出 [REJECT]），使用标准交叉熵训练。
  - **Stage II: 列表式反馈对齐**：将同一视频的在线候选按用户行为分为6个偏好等级（当前用户互动点击 > 当前用户点击 > 其他用户互动点击 > 其他用户点击 > 曝光未点击 > 检索未曝光）。对每个点击候选，用列表 Softmax DPO 对比其与所有更低级候选，损失函数包含 SFT 锚点项。
  - **Stage III: 偏好内化在线策略蒸馏 (PIOPD)**：教师模型额外接收点击查询作为后验特权信号（随机位置插入），学生模型用标准输入进行在线采样。在采样轨迹的每个前缀上，学生与冻结教师进行双向 KL 蒸馏（FKL+RKL），同时保留 SFT 损失、熵正则、R-Drop 和 FGM 稳定训练。训练后丢弃教师，部署学生模型。

- 渐进三阶段训练（SFT → 列表对齐 → PIOPD）优于直接 SFT → PIOPD 或单独列表对齐。
- 证据字段中，多模态摘要和协同锚点的存在对 HR 提升最大；紧凑 [SEP] 格式远优于冗长指令 prompt。

## 7. 优点

- **端到端生成取代级联流水线**：简化系统架构，避免多级优化碎片问题，支持紧凑提示内包含多种证据源，良好适应严格延迟预算。
- **PIOPD 无需额外奖励模型**：通过后验点击查询作为教师特权信号，在蒸馏过程中隐式内化用户偏好，避免单独训练奖励模型的偏差和奖励破解风险。
- **渐进式偏好内化设计合理**：Stage I 建立基础生成能力，Stage II 提供列表级粗粒度偏好，Stage III 进行 token 级精调，三种信号互补，训练稳定且效果最优。
- **拒绝式生成机制**：通过 [REJECT] token 让模型自主学习何时不推荐，有效降低风控 bad-case，提升用户体验。
- **工业级验证**：在快手主 feed 大规模 A/B 测试，展示显著的业务收益，证明方法的实用性和鲁棒性。
- **人工评估验证**：不仅看 CTR 等统计指标，还通过人工标注确认质量提升，避免指标膨胀。
