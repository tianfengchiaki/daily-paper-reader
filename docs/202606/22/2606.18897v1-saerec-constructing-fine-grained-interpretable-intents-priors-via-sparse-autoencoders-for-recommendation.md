## 摘要
基于意图的推荐系统通过建模用户行为背后的潜在动机，在提高准确性和可解释性方面受到了广泛关注。现有模型大多通过聚类或原型学习直接从用户序列中得出意图。然而，它们对序列质量敏感，需要预设意图数量，且缺乏显式的语义基础。这些问题导致意图集不完整且粗糙，限制了推荐的有效性。在本文中，我们提出用于基于意图推荐的稀疏自编码器（SAERec），这是一种新颖的推荐器，能够从文本语料库中自动构建细粒度且可解释的意图空间以指导推荐。SAERec不将文本视为辅助信号，而是将其作为高信息密度的证据用于意图构建。具体来说，我们首先通过使用稀疏自编码器（SAE）解耦和解释文本嵌入，从大型语言模型（LLM）的潜在空间中提取一组全面的细粒度可解释意图，从而将意图相关语义与文本噪声分离。然后，对于每个用户，我们从该集合中检索相关意图作为先验来指导推荐。其中包含匹配用户当前兴趣的个人意图，以及捕捉用户之间共享的一般项目模式的公共意图（例如质量、价格）。最后，为了将检索到的意图融入序列建模，我们提出了一种多分支注意力机制，用于捕获时间依赖性并注入个人和公共意图信号，随后通过自适应融合层构建最终的用户表示以进行推荐。在公共数据集上的大量实验证明了SAERec的优越性，它始终优于最先进的基线，同时提供人类可理解的解释。

## Abstract
Intent-based recommender systems have gained significant attention for improving accuracy and interpretability by modeling the underlying motivations behind user behaviors. Most existing models derive intents directly from user sequences via clustering or prototype learning. However, they are sensitive to sequence quality, require presetting the number of intents, and lack explicit semantic grounding. These issues lead to an incomplete and coarse intent set and limit the effectiveness of recommendation. In this paper, we propose the Sparse Autoencoder for intent-based recommendation (SAERec), a novel recommender that automatically constructs a fine-grained and interpretable intent space from a textual corpus to guide recommendation. Rather than treating texts as side signals, SAERec leverages them as high information density evidence for intent construction. Specifically, we first extract a comprehensive set of fine-grained interpretable intents from the latent space of large language models (LLMs) by using a sparse autoencoder (SAE) to disentangle and interpret text embeddings, which isolates intent-related semantics from textual noise. Then, for each user, we retrieve relevant intents from this set as priors to guide recommendation. It contains personal intents matching a user's current interests and public intents capturing general item patterns shared across users (e.g., quality, price). Finally, to integrate retrieved intents into sequence modeling, we propose a multi-branch attention mechanism that captures temporal dependencies and injects both personal and public intent signals, followed by an adaptive fusion layer to construct the final user representation for recommendation. Extensive experiments on public datasets demonstrate the superiority of SAERec, consistently outperforming state-of-the-art baselines while providing human-understandable explanations.

- **背景**：基于意图的推荐系统通过建模用户行为背后的潜在动机来提升准确性和可解释性。现有方法大多从用户交互序列中通过聚类或原型学习直接推断意图。
- **问题**：这些方法存在三大局限：(1) 意图与序列质量耦合，稀疏或噪声序列会导致不可靠的意图表示；(2) 需要预设意图数量，过少难以覆盖用户多样性，过多则引入冗余；(3) 学到的意图缺乏显式语义，难以解释和在下游场景中应用，导致意图集不完整且粗糙。
- **核心含义**：本文提出**SAERec**，通过稀疏自编码器从文本语料（用户评论）中自动构建细粒度、可解释的意图空间作为先验知识，从而指导推荐，解决现有方法对序列质量的依赖和语义缺失问题。

### 2. 论文提出的方法论
- **核心思想**：利用文本语料（评论/商品描述）作为高信息密度证据，通过SAE从预训练语言模型（P5）的稠密文本嵌入中解耦出稀疏、可解释的语义方向，再通过LLM自动筛选出与推荐相关的意图；随后采用双层级检索（个人意图+公共意图）为用户选择相关意图先验；最后通过多分支注意力机制融合意图信号与序列时间依赖，生成最终用户表示。
- **关键技术细节与流程**：
  1. **意图集构建**：
     - 用推荐感知的LLM（P5）编码评论文本得到稠密嵌入 \(\mathbf{e}_i\)。
     - 训练Top-K稀疏自编码器（SAE）：编码器将 \(\mathbf{e}_i\) 映射到高维稀疏特征 \(\mathbf{z}_i\)，解码器重构 \(\hat{\mathbf{e}}_i\)，损失为MSE。编码器权重矩阵 \(\mathbf{W}_{\text{enc}}\) 的每一列定义了一个潜在语义方向 \(\mathbf{c}_m\)，构成候选意图集 \(\mathcal{C}\)。
  2. **意图过滤与语义解释**：
     - 对每个 \(\mathbf{c}_m\)，通过互信息最大化选取最相关的 \(Z\) 个词语作为解释集 \(\mathcal{I}_m\)。
     - 用LLM（Mistral-7B）根据 \(\mathcal{I}_m\) 判断该方向是否对应有意义的推荐意图，仅保留“Yes”的向量形成最终意图集 \(\mathcal{C}^*\)。
  3. **双层级意图检索**：
     - **个人意图**：将用户序列编码为 \(\mathbf{h}_T\)，通过可学习映射将 \(\mathbf{c}_i\) 映射到同一空间，按余弦相似度选取 top-S 作为 \(\mathcal{C}^{(u)}_{\text{per}}\)。
     - **公共意图**：利用EMA平滑全批量激活频率，选取全局一致的 top-S 意图作为 \(\mathcal{C}_{\text{pub}}\)。
  4. **基于意图的序列学习**：
     - 多分支注意力机制：包含个人-用户意图注意力、公共-用户意图注意力和序列自注意力三个分支，分别输出 \(\mathbf{P}_{\text{per}}, \mathbf{P}_{\text{pub}}, \mathbf{P}_{g}\)。
     - 自适应融合层：根据用户上下文 \(\mathbf{H}_u\) 动态加权三个分支，得到融合表示 \(\mathbf{P}_f(u)\)。
  5. **优化目标**：交叉熵损失 + L2正则化。

### 7. 优点
1. **新颖的意图构建范式**：首次将SAE应用于推荐系统的意图发现，从文本语料中无监督地提取细粒度、可解释的意图，摆脱对序列质量和预设意图数量的依赖。
2. **双层级意图设计**：同时利用个人意图（个性化）和公共意图（泛化），通过EMA稳定公共意图检索，兼顾个性与共性。
3. **高效的多分支融合**：自适应权重融合三个注意力分支，动态平衡个性、共性和时序信息。
4. **可解释性强**：每个意图具有关键词和语义标签，可以进行人为干预与验证，提供人类可理解的推荐理由。
5. **鲁棒性好**：对评论文本缺失不敏感，重用意图集降低再训练成本。
