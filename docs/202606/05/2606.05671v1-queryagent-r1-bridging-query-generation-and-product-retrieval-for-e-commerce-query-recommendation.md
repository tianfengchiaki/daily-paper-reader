## 摘要
电商搜索中的查询推荐旨在主动建议与用户潜在兴趣匹配的查询。然而，现有方法主要优化查询层面的相关性，忽略了检索到的产品是否与用户的下游偏好一致。这种不匹配往往导致高查询点击率（CTR）但低产品转化率（CVR）。为弥合这一差距，我们提出QueryAgent-R1，一种记忆增强的智能体框架，通过检索链优化来改善端到端对齐。我们的QueryAgent-R1将查询生成锚定于实际库存检索，使智能体能够基于检索到的产品进行验证和优化查询。我们还在智能体强化学习（RL）过程中设计了一致性奖励，以联合优化查询相关性和下游参与度。此外，我们构建了一个记忆抽象模块以实现高效的用户画像。为支持离线评估，我们基于专有工业数据和公开数据集构建了两个数据集，在这两个数据集上QueryAgent-R1始终优于强基线。此外，在大型生产平台上，QueryAgent-R1在在线A/B测试中将查询CTR提升了2.9%，引导CVR提升了3.1%。

## Abstract
Query recommendation in e-commerce search aims to proactively suggest queries that match users' potential interests. However, existing methods mainly optimize query-level relevance, while neglecting whether the retrieved products align with users' downstream preferences. This mismatch often leads to high query click through rates (CTR) but low product conversion rates (CVR). To bridge this gap, we propose QueryAgent-R1, a memory-augmented agentic framework that improves end-to-end alignment via chain-of-retrieval optimization. Our QueryAgent-R1 grounds query generation in real inventory retrieval, allowing the agent to validate and refine queries based on retrieved products. We also design a consistency reward in the agentic reinforcement learning (RL) process to jointly optimize query relevance and downstream engagement. In addition, we construct a memory abstraction module for efficient user profiling. To support offline evaluation, we construct two datasets based on both proprietary industrial data and public datasets, on which QueryAgent-R1 consistently outperforms strong baselines. Moreover, on a large scale production platform, QueryAgent-R1 improves Query CTR by 2.9% and guided CVR by 3.1% in online A/B tests.

# QueryAgent-R1：电商查询推荐中的生成-检索对齐

## 1. 核心问题与研究动机

- **背景**：电商搜索中，查询推荐用于在用户输入前预填充搜索框，直接影响用户参与度和下游转化。现有方法（如协同过滤、语义检索、LLM直接生成）主要优化**查询级相关性**，即推荐一个看起来吸引人的查询，但**忽视了该查询是否真的能检索到用户愿意交互的产品**。
- **生成-检索差距**：一个查询可能吸引点击（CTR高），但检索到的产品与用户真实购买意图不匹配，导致后续转化率低（CVR低）。例如，推荐“咖啡自动售货机”可能点击率高，但检索结果缺乏用户偏好的特定型号。
- **核心目标**：弥合查询生成与产品检索之间的鸿沟，实现端到端的对齐优化：既保证查询本身相关，又能检索到用户后续会点击/转化的产品。

## 2. 方法论

### 核心思想
提出 **QueryAgent-R1**，一个**记忆增强的智能体框架**，通过以下三个关键技术组件实现：

1. **记忆抽象机制**：压缩用户三个月的长行为序列（>10⁴ tokens）为结构化画像（最新意图、兴趣图谱、价格段、潜在身份等），利用外部大模型（Qwen3-Next-80B-A3B）离线异步生成，在线通过 `Fetch_Memory` 工具调用。压缩比约10倍，保留个性化信息。
2. **产品检索沙箱**：构建包含400万真实产品的检索环境，采用混合检索（BM25稀疏+Qwen3-Embedding-0.6B稠密）+交叉编码器重排序（Qwen3-Rerank-0.6B）。智能体在生成查询时可调用 `Product_Search` 工具查看检索结果，据此调整查询，使其既能被点击又能检索到可购买产品。
3. **强化学习训练**：采用 **GDPO**（Group Reward-Decoupled Policy Optimization）进行优化。奖励函数由三部分组成：格式奖励 (`rfmt`)、工具调用奖励 (`rtool`)、命中奖励 (`rhit`)。其中命中奖励进一步分解为：
   - 查询奖励：`rq(y) = I(qy = q*) + ROUGE(qy, q*)`（精确匹配 + 软命名槽）
   - 产品奖励：`ri(y) = I(I(qy)∩I*≠∅) + ROUGE(Title(I), Title(I*))`（命中率 + 标题相似度）
   - 两种奖励加权求和得到 `rhit`。
   - 整体奖励：`R(y) = λ_fmt * rfmt + λ_tool * rtool + λ_hit * rhit`

- **问题形式化**：搜索栏推荐被建模为**双跳优化**：最大化 `P(点击查询 | 历史) × P(检索产品与真实点击产品有交集 | 历史)`。
