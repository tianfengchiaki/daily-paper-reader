## 摘要
定向广告系统可以将广告主选择的受众与展示可见用户行为的广告单元配对。当交互行为仍然与引发它的广告活动相关联时，广告主可能收到与用户相关的观察结果，而不仅仅是聚合报告。我们将该通道建模为用于属性推断的带噪预言机。该模型将目标谓词、曝光、交互和披露区分开来。这些边界捕捉了资格与投放之间的差距，以及交互与广告主可见性之间的差距。我们使用公开数据校准的合成人群构建了一个可重复的基准测试，每个合成个体具有已知的敏感标签。生成的广告活动语义层提供了主题变体和先验响应。模拟器生成真实数据、事件轨迹、披露的观察结果和指标。评估比较了常见广告活动与披露定义下的贝叶斯攻击、监督攻击、正例无标签攻击和自适应攻击。最终评估使用了四个主题变体、七个模拟器种子和两种交互设置。具有身份曝光的重复广告活动产生了可测量但有界的推断信号。在160个广告活动下，贝叶斯攻击和监督攻击在主设置中达到约0.64 AUC，在较高交互设置中达到约0.65 AUC。披露策略是最强的控制手段。聚合报告移除了与用户关联的评估预言机输入。类型过滤和随机披露减少了释放的信号。结果为交互式定向广告中的隐私提供了一个模型、工件和防御评估方法。代码见 https://github.com/P-HOW/Interactive-Ad-Oracle。

## Abstract
Targeted advertising systems can pair audiences selected by advertisers with ad units that expose visible user actions. When an interaction remains linked to the campaign that elicited it, the advertiser may receive an observation tied to a user rather than only an aggregate report. We model that channel as a noisy oracle for attribute inference. The model separates targeting predicates, exposure, interaction, and disclosure. These boundaries capture the gap between eligibility and delivery, and the gap between interaction and advertiser visibility.   We build a reproducible benchmark using synthetic populations calibrated with public data, each with known sensitive labels. A generated campaign semantics layer provides topic variants and response priors. The simulator generates the ground truth, event traces, disclosed observations, and metrics. The evaluation compares Bayesian, supervised, positive and unlabeled, and adaptive attacks under common campaign and disclosure definitions.   The final evaluation uses four topic variants, seven simulator seeds, and two interaction settings. Repeated campaigns with identity exposure produce measurable but bounded inference signal. At $160$ campaigns, Bayesian and supervised attacks reach about $0.64$ AUC in the main setting and about $0.65$ AUC in the higher interaction setting. Disclosure policy is the strongest control. Aggregate reporting removes the evaluated oracle input tied to users. Type filtering and randomized disclosure reduce the released signal. The result is a model, artifact, and defense evaluation method for privacy in interactive targeted advertising. The code is available at https://github.com/P-HOW/Interactive-Ad-Oracle.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：社交平台上的交互式定向广告允许广告主定义受众（通过“目标谓词”），当用户与广告互动（如评论、点赞）且平台将互动记录与广告主共享时，广告主能观察到具体哪个用户产生了互动。这种机制可能泄露用户敏感属性（如健康兴趣、政治倾向），形成一条隐私信道。
- **核心问题**：广告主能否通过反复投放广告并观察用户的互动记录，推断出用户的敏感属性？该问题的严重程度如何？哪些因素（如广告次数、互动率、披露策略）影响推断风险？平台有哪些防御手段？
- **整体含义**：论文首次将交互式定向广告建模为带噪属性推断预言机，系统研究了其隐私风险，并提供了可重复的基准测试和防御评估方法。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：将广告投放过程抽象为一个噪声预言机，分离出四个阶段：
  - **定向谓词（Targeting Predicate）**：广告主选择的用户条件（如“年龄25-35且兴趣为健身”）。
  - **曝光（Exposure）**：广告实际投放到用户设备。
  - **交互（Interaction）**：用户点击、评论等行为。
  - **披露（Disclosure）**：平台向广告主展示哪些信息（如聚合报告或带有用户身份的详细记录）。
- **关键技术细节**：
  - **用户模型**：每个用户有特征向量 \(X_u\) 和隐藏敏感属性 \(S_u\)（二值）。广告主不知道 \(S_u\)，但可以通过广告活动观察用户互动历史 \(H_u^{(T)}\)。
  - **广告活动定义**：\(c = (g_c, a_c, b_c)\)，其中 \(g_c\) 为谓词函数，\(a_c\) 为创意主题，\(b_c\) 为预算。合法广告活动需满足最小受众规模等约束。
  - **事件生成**：曝光 \(E_{u,c} \sim \text{Bernoulli}(p_E)\)，且满足“定向单调性”：符合谓词的用户曝光概率更高。交互 \(R_{u,c}\) 仅在曝光后发生，概率 \(p_R\) 依赖于用户特征、敏感属性和广告创意。
  - **披露策略**：定义了多种披露映射 \(D\)，包括：
    - 身份曝光：对每次交互都返回用户ID和互动类型。
    - 类型过滤：只返回指定互动类型（如仅评论）。
    - 随机身份披露：以概率 \(\rho\) 随机丢弃交互记录。
    - 阈值披露：仅当某个广告活动的交互总数≥k时才披露。
    - 聚合报告：只返回总交互次数，不返回用户级别的记录。
  - **攻击方法**：
    - **贝叶斯攻击**：假设给定 \(S_u\) 时各次广告观察条件独立，通过贝叶斯公式更新后验概率。
    - **监督影子攻击**：用影子用户数据训练分类器（逻辑回归、随机森林、梯度提升树），将观察历史映射为特征，直接预测 \(S_u\)。
    - **正例无标签攻击**：把缺席视为负类（封闭世界）或未标注（开放世界），对比不同假设。
    - **自适应攻击**：广告主根据已获结果选择下一个最有利的广告活动，策略基于期望信息增益与成本之比。
  - **模型形式化**：给出了后验对数几率公式、自适应选择规则、停止准则等。

### 6. 主要结论与发现

- **信号存在但有界**：重复广告活动能够产生可测量的推断信号（AUC约0.64-0.65），但受限于曝光和交互噪声，信号强度有限。
- **交互率提升信号**：较高交互设置（可见交互数从1.04提升至1.33）使贝叶斯AUC从0.636升至0.654。
- **披露策略是最强控制**：聚合报告使攻击退化为随机猜测（AUC=0.5）。类型过滤降低AUC约0.05，随机披露降低AUC约0.04，阈值披露在本次模拟中效果不明显。
- **高置信度推断仍困难**：在160次广告后，仅17.2%（主设置）和29.8%（较高交互）的用户后验置信度超过0.7，表明虽然整体排序优于随机，但可靠推断需要很多交互。
- **谓词粒度影响复杂**：较窄的谓词（长度3）并未提升推断效果（AUC≈0.5），因为窄谓词减少曝光和交互机会；而较宽谓词（长度1）保留了更多可观测交互，效果更好（AUC≈0.63）。
- **自适应攻击未显著优于非自适应**：在本次实验中，基于信息增益的自适应选择未大幅降低达到置信度所需的广告数或成本。

### 7. 优点

- **系统化建模**：将定向广告的多个环节（谓词、曝光、交互、披露）分离，为隐私研究提供了清晰的形式化框架。
