## 摘要
定向广告系统可以将广告主选择的受众与展示可见用户行为的广告单元配对。当交互行为仍与引发它的广告活动相关联时，广告主可能会收到与用户关联的观察结果，而不仅仅是汇总报告。我们将该渠道建模为用于属性推断的含噪预言机。该模型分离了定位谓词、曝光、交互和披露。这些边界捕捉了资格与投放之间的差距，以及交互与广告主可见性之间的差距。我们使用公开数据校准的合成群体构建了一个可复现的基准测试，每个群体具有已知的敏感标签。生成的广告活动语义层提供主题变体和响应先验。模拟器生成真实数据、事件轨迹、披露的观察结果和指标。评估在常见的广告活动和披露定义下比较了贝叶斯、监督、正无标签和自适应攻击。最终评估使用了四个主题变体、七个模拟器种子和两种交互设置。具有身份曝光的重复广告活动产生了可测量但有界的推断信号。在160个广告活动下，贝叶斯和监督攻击在主设置中达到约0.64 AUC，在更高交互设置中达到约0.65 AUC。披露策略是最强的控制。汇总报告移除了与用户关联的评估预言机输入。类型过滤和随机化披露减少了释放的信号。结果为交互式定向广告中的隐私提供了一个模型、工件和防御评估方法。代码可在https://github.com/P-HOW/Interactive-Ad-Oracle获取。

## Abstract
Targeted advertising systems can pair audiences selected by advertisers with ad units that expose visible user actions. When an interaction remains linked to the campaign that elicited it, the advertiser may receive an observation tied to a user rather than only an aggregate report. We model that channel as a noisy oracle for attribute inference. The model separates targeting predicates, exposure, interaction, and disclosure. These boundaries capture the gap between eligibility and delivery, and the gap between interaction and advertiser visibility.   We build a reproducible benchmark using synthetic populations calibrated with public data, each with known sensitive labels. A generated campaign semantics layer provides topic variants and response priors. The simulator generates the ground truth, event traces, disclosed observations, and metrics. The evaluation compares Bayesian, supervised, positive and unlabeled, and adaptive attacks under common campaign and disclosure definitions.   The final evaluation uses four topic variants, seven simulator seeds, and two interaction settings. Repeated campaigns with identity exposure produce measurable but bounded inference signal. At $160$ campaigns, Bayesian and supervised attacks reach about $0.64$ AUC in the main setting and about $0.65$ AUC in the higher interaction setting. Disclosure policy is the strongest control. Aggregate reporting removes the evaluated oracle input tied to users. Type filtering and randomized disclosure reduce the released signal. The result is a model, artifact, and defense evaluation method for privacy in interactive targeted advertising. The code is available at https://github.com/P-HOW/Interactive-Ad-Oracle.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想

- 将交互式定向广告抽象为一个**噪声预言机（noisy oracle）**：广告主每次发起广告活动视为一次查询，查询结果（即披露的交互记录）依赖于用户对谓词的资格、曝光、交互行为以及平台的披露策略。由于投放、注意力和交互的不确定性，这是一个带噪声的观察。
- 通过**分离三个阶段**（谓词→曝光→交互→披露）来捕获资格与投放之间的差距、交互与广告主可见性之间的差距。

### 2.2 关键技术细节

- **模型组件**：
  - 用户集 \(U\)，每个用户有特征 \(X_u\) 和二进制敏感属性 \(S_u\)。
  - 广告活动 \(c = (g_c, a_c, b_c)\)，其中 \(g_c\) 是目标谓词（布尔函数作用于用户特征），\(a_c\) 是创意/主题，\(b_c\) 是预算或归一化成本。
  - 合法广告活动空间 \(C_{legal}\) 受最小受众规模 \(m\)、预算上限 \(B_{max}\)、允许谓词集 \(G_{allowed}\) 约束。
  - 曝光事件 \(E_{u,c} \sim \text{Bernoulli}(p_{E}(u,c))\)，满足单调性：符合谓词的用户曝光概率更高。
  - 交互事件 \(R_{u,c}\) 仅在曝光后可能发生：\(Pr(R_{u,c}=1 | E_{u,c}=0)=0\)，\(Pr(R_{u,c}=1 | E_{u,c}=1)=p_R(u,c; X_u, S_u, a_c, \theta_R)\)。
  - 披露策略 \(D\) 决定广告主能观察到什么：暴露身份的披露（\(Y_{u,c}^{id}\)）、类型过滤、随机化披露、阈值披露、聚合报告。

- **攻击目标**：推断规则 \(f: \mathcal{H} \to \{0,1\}\) 映射用户历史到敏感属性估计。自适应策略 \(\pi\) 根据前序观察选择下一个合法广告活动，受预算约束。

- **贝叶斯基线**：
  - 后验对数几率：\(\log \frac{\Pr(S_u=1|H_u^{(T)})}{\Pr(S_u=0|H_u^{(T)})} = \log \frac{\pi_0}{1-\pi_0} + \sum_{t=1}^T \log \frac{q_{c_t,1}(Y_{u,c_t})}{q_{c_t,0}(Y_{u,c_t})}\)，其中 \(q_{c,s}(y)=\Pr(Y_{u,c}=y|S_u=s,c)\) 从校准数据估计。

## 6. 论文的主要结论与发现

1. **RQ1**：重复广告活动结合身份曝光能产生**可测量但有界的推断信号**。在160个活动后，贝叶斯和监督攻击AUC约0.64（主设置）~0.65（更高交互设置），高于先验基线（0.5），但远非完美。
2. **RQ2**：推断信号随广告活动数量和交互密度增加而增强，但受限于投放噪声和交互噪声。谓词粒度更细并不自动提高推断性能（长度3的谓词几乎接近先验，因为降低了曝光和交互机会）。
3. **RQ3**：高置信度推断（后验≥0.70）在主设置中仅覆盖少数用户（~17%），在更高交互设置中增至~30%。自适应策略可减少达到特定置信水平的成本，但效果有限。
4. **RQ4**：**披露策略是最强的平台控制**。聚合报告完全移除评测通道（AUC=0.5）；类型过滤和随机化披露显著降低但未完全消除信号（AUC降至0.58-0.61）；阈值披露在当前事件分布下未有效绑定。
5. 整体结论：交互式定向广告构成一个噪声预言机，其隐私风险取决于广告活动重复性和披露设计，平台应优先在披露层进行防御。

## 7. 优点：方法或实验设计上的亮点

- **模型清晰**：将广告投放流程分解为谓词、曝光、交互、披露四阶段，形式化定义预言机，便于理论分析和防御设计。
- **可复现基准**：使用合成数据+公开校准，避免获取真实敏感标签的隐私伦理问题；提供开源代码，支持参数扫描。
- **自动主题生成**：利用LLM生成语义合理的广告主题和响应先验，提升合成数据的现实感，同时保持标签和事件由模拟器控制。
- **全面攻击对比**：覆盖贝叶斯、监督、正无标签、自适应四类攻击，并分离推断规则与活动选择策略，支持细粒度分析。
- **防御评估方法**：将防御视为披露映射的变换，在相同事件轨迹下比较，公平性高；结果直接指导平台设计。

## 8. 不足与局限

- **合成数据局限**：所有结果基于合成群体，与真实平台行为存在差距（如用户交互模式、平台优化算法、跟踪精度等未建模）。缺乏真实平台验证（仅建议使用同意账户进行界面验证）。
- **标签单一**：仅评估一个敏感属性（健康兴趣），其他属性（政治、财务等）可能具有不同相关性和易推断性。
- **攻击能力限制**：假设攻击者知道目标用户身份（通过交互曝光），但未考虑用户可能不交互或被多个广告主观测的实际情况。自适应策略仅基于信息增益，未探索更复杂的主动攻击。
- **防御评估有限**：阈值披露设定不够严格导致未绑定；随机化披露的概率\(\rho\)未优化；聚合报告虽然阻断当前通道，但未考虑基于聚合统计的推断攻击（论文提及但未评估）。
- **未考虑跨平台或外部数据融合**：攻击者可能结合外部数据源（如数据中介）增强推断，论文明确排除了这一能力。
- **计算资源量化缺失**：未报告实验运行所需的算力和时间，不利于复现者预估成本。
